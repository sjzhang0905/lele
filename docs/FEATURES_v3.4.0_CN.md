# LELE v3.4.0：验收修复、等值面叠加与 ESP 映射

## 本版修复

| 问题 | 修复后的行为 |
|---|---|
| A1：普通 FCHK / 无频率 Molden 加载到主窗口时阶段索引越界 | 为快照建立合法阶段；旧工程即使缺阶段也能显示；不把快照标为优化收敛 |

## 用电子密度表面显示 ESP

1. 打开电子密度 CUBE；VASP 可打开 CHGCAR。
2. 在等值面控制区域点 **Import another field file…**，选同一构型的 ESP / 电势 CUBE，或 VASP LOCPOT。也可以使用文件自带的多个数据场。
3. 点 **Surface layers / ESP color mapping…**。保留一行正等值面，将 **Source field** 选为电子密度，输入密度等值面数值。该数值使用密度场本身的单位。
4. 点这一行的 **Uniform color…**，在 **Color field** 中选择电势网格。确认后按钮会显示 **Field N colors…**。
5. 选择配色、自动色阶或固定 Min/Max，勾选 **Show color scale**，依次点两次 OK。

默认 Red-white-blue：负值红、零值白、正值蓝。Blue-white-red 反转两端；Viridis 是连续单向配色。自动范围取表面取样值的最大绝对值，关于零对称；固定范围便于比较多张图，超出端点的值使用端点颜色。红白蓝固定范围必须跨零。色标使用着色场的单位，与密度等值面的单位独立。

**这是显示已有电势场的功能，不会从原子、电荷或轨道系数计算 ESP。** 普通 CUBE 的物理含义/单位不总能从文件确定；未识别单位保留为来源单位，不自动宣称是 Hartree。VASP LOCPOT 以 eV 记录势，其具体内容取决于计算设置；LVTOT 的总局域势可含交换关联项，不能把所有 LOCPOT 都直接称作分子 ESP。请根据生成网格的计算选择适当数据通道。

## 同时叠加多个等值面

在同一表格中点 **Add layer**，逐行设置 **Source field**、带符号的等值面值、颜色、透明度和 Surface/Wireframe/Points。每行可使用不同数据场，也可选择独立着色场；Show 控制显隐，Remove 删除该行。色标标题中的 Layer 编号对应表格原始行号。

选定具体 Source field 的层不会因主面板 Dataset 切换而改变。选 **Active Dataset** 的层仍跟随当前数据场。**Use basic +/− controls** 清除自定义层，恢复简单正负等值面控制。当前最多 32 层、4 个可见色标；各层可自行隐藏色标。

## 对齐、覆盖与保存

- 追加网格会核对原子元素、数量、顺序、坐标；周期场还核对晶胞。允许不同网格原点、点数、间距和倾斜方向，前提是处于同一物理坐标系。原子坐标容差为 0.0002 Å；不自动拟合、重排或平移无关结构。
- 在真实表面顶点做笛卡尔坐标转换和三线性插值，法向偏移为零。周期场按自己的网格周期取样；非周期场不会向外推。部分表面超出着色网格时显示灰色并提示；完全无覆盖时省略该映射层并提示。
- 刚性重设方向与显示对齐时，表面和着色网格使用相同变换。Boundary 仅复制周期场；周期网格大小与结构晶胞不符时提示并禁用该场的复制。
- 改变结构导致旧网格脱离时，所有关联等值面与色标一起隐藏；撤销可恢复。混占结构不接受没有相应混占信息的网格。
- 保存 `.lele` 工程会嵌入所有网格和各层配置。工程重新打开不依赖原始 CUBE/LOCPOT 文件；PNG、GIF 导出保留映射和色标。导出 CUBE 仍只输出当前 Dataset 的数值网格，表面样式请用工程或图片保存。
- 导入可取消；长时间生成/取样显示进度。合计最多 64,000,000 个标量值，每个场最多 512 个表面副本，每层最多 20,000,000 个显示顶点；超限会提示。

## 随包示例

`examples/esp_mapping_v340/` 包含两个不同分辨率的解析网格、直接可打开的映射/叠加工程及预览。数据明确标为人工解析示例，只用于检查显示，不代表真实分子的量化计算结果。

Windows 源码运行仍使用根目录 `start_windows.bat`；构建单文件程序使用 `build_windows.bat`。本包提供源码及构建脚本，不包含本次未经实机验证的 Windows EXE。
