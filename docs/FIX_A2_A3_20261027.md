# LELE 1.7.0 — A2 / A3 acceptance repair

Date: 2026-10-27

- **A2:** Pasting atoms into a document with attached volumetric data now detaches
  the obsolete field after the Undo snapshot is recorded. The renderer is refreshed
  without that field; Ctrl+Z restores both the pre-paste structure and the original
  volumetric data.
- **A3:** The Edit-page element selector is now refreshed through a shared helper
  after geometry edits, so a newly pasted element is immediately selectable. The
  same helper is used when switching frames to keep the behavior consistent.

Regression tests were added to `tests/test_selection_ui_v090.py` for both behaviors.
