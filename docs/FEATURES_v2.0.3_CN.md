# LELE v2.0.3 氢键与文件视图

日期：2026-10-29（北京时间）。

## Ctrl+H 绘制氢键

选中两个原子，通常为 H 和受体原子，然后按 **Ctrl+H**，即可添加青色虚线氢键。
再次按 Ctrl+H 移除这条连接，**Ctrl+Z** 撤销。相同操作也位于
**Edit → Toggle selected hydrogen bond**，以及左侧 **Edit** 页的按钮。
欢迎页和 Help 中已补充快捷键。

**Ctrl+B** 继续操作普通键。手动画出的氢键不参与普通键连接图，因此不会让
Select fragment、Ctrl+G 或 Alt 拖动把两个分子当成同一共价片段。
即使未勾选自动氢键，手动画出的虚线仍会显示。普通键和氢键分别管理。

Style 页的 **Automatic hydrogen bonds (dashed)** 保留原有几何候选显示。
开启时，Ctrl+H 也可隐藏选中原子对的已有自动候选；重新添加手动连接后不会重复画线。
手动连接允许用户自己指定原子对，不强制套用自动候选的元素、距离和角度条件。

周期结构在添加时选择最近周期像，此后移动坐标保留该连接的周期像。
Boundary、轨迹显示对齐与真实扩胞会映射手动连接。删除原子会同步删除相关氢键；
LELE 内部复制/粘贴保留选中原子间的手动连接。更改可以撤销。
氢键编辑作用于当前帧；普通坐标导出格式不保存这些会话显示注记。

## 文件间切换保留视图

每个已打开文件单独保存本次会话中的以下设置：

- 相机方向、观察中心、平移、缩放、透视/正交投影和裁剪范围。
- 显示风格、元素配色、背景、原子尺寸、键粗细、普通键与自动氢键开关。
- 标签、字体、颜色、坐标轴与晶胞开关。
- Boundary 范围、偶极显示参数、等值面数值、可见性和透明度。
- 所选预设和 Custom 手动外观状态；各控制面板同步恢复。

例如：A 文件设为深色背景并旋转到侧面，B 文件改成浅色并放大；切回 A 时仍是
A 的深色侧视图，再切回 B 则恢复 B 的浅色放大视图。
逐原子的颜色/显隐仍由各文件自身的原子显示设置管理。

新文件首次打开时继承当时的外观参数，并自动取景；此后各文件独立调整。
文件树根节点、帧、频率、能量结果及分析窗口跳帧共用同一恢复流程，
不会因返回频率参考结构再次重置已保存的文件相机。
纯能量页不会把其他文件的隐藏相机误存为自己的视图。

这些设置用于当前打开会话；关闭程序后重新打开文件会按初始设置取景。
需要复用配色时仍可使用已有的 **Save current appearance as preset…**。
