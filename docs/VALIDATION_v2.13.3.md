# LELE v2.13.3 修复与验证记录

日期：2026-11-03。基于当前 v2.13.2 源码包修改。

## 修改内容

1. 修复选中两个原子后，右下角键长输入框撑高底部信息栏、压缩画布的问题。底栏在载入结构时即按当前 Qt 样式和字号的原生控件高度预留空间；显示或隐藏键长、键角、二面角输入框时，不再改变底栏高度。摘要文字保持紧凑并垂直居中，数值输入和 Set 按钮继续正常工作。
2. 新建显示选项、默认 Classic ball and stick 预设以及 Light background 按钮均使用纯白 `#FFFFFF`。已有项目和自定义预设中明确保存的颜色继续按其保存值读取。

## 验证结果

- 源码完整回归：**981 项测试、78 个子测试全部通过，零失败、零错误、零跳过**。原有 PQR/CUBE 回归测试包含在内。
- 布局检查：Qt Windows、Fusion 两种样式 × 9/11/14 pt 三种字号 × 1024×768、1380×850、1920×1080 三种窗口尺寸，共 **18 组配置**。每组依次切换未选、选 1/2/3/4 个原子、清空和重复选择；窗口、画布和底栏尺寸始终保持一致。数值框、按钮可完整显示，摘要标签保持紧凑。
- 生产 Qt/VTK 窗口：通过坐标表鼠标点击完成相同选择流程；键长通过 Enter 修改成功，撤销恢复原值，画布尺寸保持一致。
- 背景：默认选项与默认预设均为 `#FFFFFF`，VTK 渲染器背景为 `(1,1,1)`。实际渲染图片两个上角均为 RGB `(255,255,255)`；Dark presentation → Light background 以及返回默认预设均恢复纯白。

1380×850、默认 Fusion 样式下的观察结果（像素）：

| 状态 | 修复前底栏高度 | 修复后底栏高度 | 修复前画布 | 修复后画布 |
| --- | ---: | ---: | --- | --- |
| 未选择 / 选择 1 个原子 | 21 | 28 | 1022×626 | 1022×620 |
| 选择 2 / 3 / 4 个原子 | 28 | 28 | 1022×620 | 1022×620 |
| 清空选择 | 21 | 28 | 1022×626 | 1022×620 |

这里的固定高度来自原生输入控件的尺寸提示，避免压缩控件文字或上下箭头；不同系统样式和字号可得到不同的稳定高度。

在源码目录安装依赖后，可运行原有测试。要启用全部真实样例检查，需提供先前验收使用的私有 POSCAR、QE、CP2K、CIF 和旋转脚本路径；这些用户样例不随源码重新分发。完整回归使用的环境变量名称沿用 `VALIDATION_v2.13.2.md`。

Linux 无显示服务器且 VTK 支持 EGL 时，可运行：

```bash
QT_QPA_PLATFORM=offscreen VTK_DEFAULT_OPENGL_WINDOW=vtkEGLRenderWindow \
EGL_PLATFORM=surfaceless PYTHONPATH=. \
python docs/qa_v2.13.3/check_native.py /tmp/lele-v2133-window
```

本次环境为 Linux、Python 3.12、PySide6 6.12.0、VTK 9.7.1。实际窗口检查保留生产 Qt 控件、交互和 VTK 场景，仅将原生显示窗口切换为 EGL 离屏目标。Qt Windows 样式检查不等于 Windows 操作系统实机验证。本次交付为源码包，未构建或实机验证 Windows EXE。
