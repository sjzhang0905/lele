# LELE v2.13.2：PQR / CUBE 修复

2026-11-03。针对 v2.13.1 全量验收报告的 A1、A2。

## PQR：元素与坐标采用同一种记录布局

旧读取器回退到空白字段读取坐标时，仍按 PDB 固定列截取原子名，因此 `ATOM 1 ...` 会被跳过，其他布局可能把 O 读成 N 或 Sn。

新版支持 ATOM/HETATM、单空格/多个空格/制表符、可选 Chain ID、超出固定列宽的坐标、带 BOM/UTF-16 的文本，以及独立的固定列宽 PQR 分支。元素和坐标从同一记录中取得，非法原子行报告行号，避免静默丢失原子。常见蛋白质/核酸残基中的 CA、CD1、NE2、HG1 按原子标签解释；离子残基及明确的元素名称保留其元素含义。PQR 未明确给出元素时仍需按原子命名约定识别，不声称能消除任意非标准标签的歧义。

报告的三个布局现在均得到 **O、(1,2,3) Å**；正常固定列宽对照保持一致。旧转换接口和软件导入使用同一读取器。

## CUBE：共享原子与网格单位处理

新增统一的 CUBE 头部适配层。全负网格计数按 Å 长度约定处理，正网格计数按 Bohr；为 ASE 提供正维度及统一长度单位。原子坐标、晶胞、网格原点和体素矢量同步转换，原文件不改写，标量场数值不按长度比例缩放。原有 Volume 使用的 float32 存储保持不变。

网格计数符号与负原子数的轨道标签分别处理；保留 ASE 对数据顺序、单轨道标签和 CASTEP 重复边界面的处理。混合符号、零维度及无效几何头部明确拒绝。体数据不完整、含非有限值、超过现有点数上限或属于多通道时，保留有效原子结构并说明体数据不可用，不自动选择某个通道。取消操作继续传播为取消。

最小负计数示例现在得到 **O、(1.25,2.25,3.25) Å**、原点 **(1,2,3) Å** 和 **0.5 Å** 体素；2×2×2 网格可用。正常 Bohr 对照、斜网格、负原子数标签、五种结构导出与项目重开均已检查。

本次新增 69 个回归用例，已纳入完整测试集；原验收的 114 个独立用例也全部复跑。详见 [复验记录](VALIDATION_v2.13.2.md)。
