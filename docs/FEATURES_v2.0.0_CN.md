# LELE v2.0.0 使用说明

## 按选中原子筛选振动

1. 打开包含频率结果的 Gaussian 或 ORCA 输出，选中感兴趣的原子。
2. 点击 Files 页 **Find vibrations…**，或 Analysis → **Find vibrations by selected atoms…**。
3. 在窗口中选择频率计算段；点击 **Use current atom selection** 更新选区。
4. 默认按选区位移占比降序排列，可设置最低百分比，或只显示虚频。
5. 点击 **Play selected mode** 或双击一行，播放该计算段的对应模式。
6. **Show static displacement arrows** 切到参考构型并显示位移箭头。
   左侧 Vibration 控件可调整最大箭头长度、仅对选中原子显示箭头。
7. **Export shown modes CSV…** 导出当前筛选后的模式与选区。

位移占比的定义为 `Σ选中原子 |d|² / Σ全部原子 |d|²`，d 为读取到的笛卡尔位移向量。
它表示运动位移的相对参与程度，不是质量加权的振动能量贡献。缺失或全零的位移表
没有可定义的占比，表格显示“—”；这类模式不会产生虚构动画。
检查 TS 时，应在所属最终频率验证段中观察虚频运动，不能将初始/更新 Hessian 的模式
自动视作最终 TS 的验证结果。

## 跨帧几何参数曲线

- 按顺序选中 2、3、4 个原子，点击 Files → **Geometry curves…**，
  自动加入键长、键角或二面角监控。
- 可在三维窗口重新选择原子，再点击 **Add current selection**，同时监控多个参数。
- 自定义参数使用从 1 开始的原子编号，以空格或逗号分隔。

| 参数 | 第一组 | 第二组 |
|---|---|---|
| Distance | 2 个原子 | 留空 |
| Angle | 3 个原子，中间原子为顶点 | 留空 |
| Dihedral | 4 个原子，沿第 2→3 原子的键 | 留空 |
| Plane angle | 至少 3 个平面原子 | 至少 3 个平面原子 |
| Vector angle | 2 个原子，定义有向向量 | 2 个原子 |
| Point–plane distance | 1 个原子 | 至少 3 个平面原子 |
| Point–line distance | 1 个原子 | 2 个直线原子 |
| Vector–plane angle | 2 个向量原子 | 至少 3 个平面原子 |

平面采用等权最小二乘拟合；平面夹角和向量与平面的夹角取 0–90°。
距离与角度分别绘制，表格列出有效点数、最小、最大、平均和标准差。
**Unwrap dihedrals** 可连续展开 ±180° 附近的二面角。
周期体系默认使用打印坐标；新建监控前勾选 **Use nearest periodic images** 才使用最近周期像。
不改变源结构。退化几何、原子顺序不同的帧会保留为空缺，不会补零或连接假点。

窗口默认使用当前浏览的轨迹。在 NEB 窗口选择路径快照或单个 image 历史后，
打开几何曲线，或点击 **Use current trajectory**，即沿该序列分析。
也可从下拉框切换已有阶段/路径组。点击曲线数据点跳到它的真实源帧，保持该序列播放范围。
**Refresh source geometry** 在几何编辑后重新计算监控值；关闭再打开窗口仍保留本次会话的监控列表。
CSV 包含序列位置、源帧编号、阶段、NEB iteration/image 和全部参数，缺失值留空。

## 轨迹统一朝向

- 在 Files 页勾选 **Align trajectory for display**，默认以当前帧为参考，对齐全部原子。
- **Settings…** 可选择当前轨迹中的参考帧，以及全部原子或当前选定的骨架。
- 通过平移和不含镜像的旋转进行最小二乘拟合；选定骨架之外的真实构象变化仍会保留。
- 原始坐标、晶胞、能量、测量值和结构导出保持原始参考系；PNG、播放和 GIF 采用对齐画面。
- 显示的晶胞、abc 方向、偶极向量和已拟合平面跟随同一变换。
- 关闭勾选立即恢复原始显示。编辑坐标或键前须先关闭显示对齐。
- 原子数/元素顺序与参考不一致时，不套用变换，并在 Results/info 标出原因。

## xTB 只有能量时的左侧列表

左侧 Files 树按计算段列出每一个没有对应坐标的能量步骤。
点击可查看该步编号、Eh/eV/kcal/mol 能量和输出源行；中间显示结果页，
不显示结构、不创建空帧，也不会把最终结构配给没有坐标的中间步骤。
文件仅有部分结构时，无坐标能量步骤仍可独立选择；有结构的条目保留正常浏览。
完整能量曲线、CSV 和 HOMO/LUMO 按钮继续可用，结构文件不是必需的配套文件。

## 构建 Windows EXE

本版交付源码。Windows 下重新执行 `build_windows.bat`，交付整个 `dist\LELE` 文件夹。
Linux Qt/VTK 离屏验证不替代 Windows 实机验收。
