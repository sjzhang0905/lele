# LELE v3.5.2：CHGCAR 重命名识别与读取加速

日期：2026-11-09。基于 v3.5.1，保留此前启动、CUBE、AIMD 和 NMR 改动。

## 问题与修复

原版主要依赖 `CHGCAR` 等文件名识别 VASP 体数据。将本次样例改名为 `renamed_density.dat` 后，它被归类为普通 POSCAR；结构读取器随后把网格内容当成了结构后续记录，报出 `Reader failed for VASP POSCAR-like input`。

现在先检查实际内容：VASP 晶胞与原子计数、完整坐标表、随后的网格维度及数值记录。无扩展名和 `.txt`、`.dat`、`.vasp` 等常见重命名方式均可识别本次 CHGCAR；即使误加 `.cube`、`.xyz` 等扩展名，具有完整 CHGCAR 内容时也按体数据读取。普通 POSCAR、CONTCAR、速度记录及真实 CUBE/XYZ 保持各自的读取路径。

标准名称、编号副本和带前后缀的名称统一处理，例如 `CHGCAR(1)`。检测只读取结构头、坐标和少量网格数据，不扫描完整大文件；读取成功后复用格式判断，避免再次识别。

对于保留 `LOCPOT`、`ELFCAR` 等名称的文件，继续保留其电势/ELF 单位。**完全删除类型名称后，仅凭同样的数字布局不能可靠区分电荷密度、电势和 ELF；内容识别默认按 CHGCAR 电荷密度解释，并在读取说明中标明。** 电势和 ELF 文件应在名称中保留相应类型标识。

极少数很小的匿名网格与 POSCAR 的速度表可以逐字节相同。对于这种无法从内容唯一判定的情况，程序保守地保留结构解释；使用带 `CHGCAR` 的名称可明确选择体数据。这个边界情况不影响本次上传的样例。

## 数值解析优化

- VASP 标量数据改为约 1 MiB 的分块 NumPy 转换，减少逐行 Python 浮点转换和逐行小数组分配。
- 通过文本回退缓冲保留下一段尚未使用的数据，不依赖 UTF-16 等文本流中的字节偏移或反复文件定位。
- 回退缓冲以队列和位置记录未用片段；较小的 PAW 增广块按剩余值数缩小读取量，避免每个原子反复读取、复制和拆分整个大缓冲区。
- 保留每个网格的精确值数、物理行边界、PAW 增广块跳过、自旋/磁化多通道和 x 轴最快的 VASP 网格顺序。
- 保留现有 float32 体数据和按晶胞体积归一化方式，不裁剪负值、不降采样。读取取消、非有限值、截断和多余值检查继续有效。

## 本次实际文件验证

上传样例：8,057,934 字节，6 个原子（Mo₂S₄），网格 **48 × 48 × 192**，包含 6 段 PAW 增广占据数据。

以原版使用标准 `CHGCAR` 文件名读取的结果作为对照，新版对标准名、编号副本、无扩展名及多种重命名副本进行验证。全部网格 float32 数值摘要一致：

```text
52ef3ef764df5a11fbb020a7c3e033152d3ea3ad251c2b8621cd394d077030b0
```

电荷密度单位仍为 `e/Å³`；PAW 增广数据不混入规则网格。原始样例未收入公开源码包，测试通过 `LELE_CHGCAR_EXAMPLE` 环境变量读取本地样例。

## 性能

同一 Linux / Python 3.12 环境下，串行运行、每次使用新进程，预热所需模块后对完整 `load_document` 读取取 3 次中位数。文件系统缓存已预热；不含依赖导入、文件树、等值面生成和 GPU 绘制时间，不能作为 Windows EXE 的实测耗时。

| 文件 | v3.5.1 | v3.5.2 | 加速比 |
|---|---:|---:|---:|
| 本次实际 CHGCAR，8.06 MB | 0.2975 s | 0.0542 s | 5.49 倍 |
| 合成 CHGCAR，119.44 MB，144³ × 2 通道，含 PAW 增广 | 4.0564 s | 0.5701 s | 7.11 倍 |

两组测试的完整几何、网格、标签和单位摘要均与原版一致。进程峰值内存：实际样例约 66.8 → 73.3 MiB；合成大文件约 108.9 → 104.4 MiB。分块缓冲有一定开销，因此不声称所有文件都降低内存占用。

复现工具位于 `tools/performance/benchmark_chgcar.py`：

```bash
python tools/performance/benchmark_chgcar.py --baseline /path/to/old/LELE --current /path/to/new/LELE --directory /path/to/bench --input /path/to/your/CHGCAR --repeats 3
```

不提供 `--input` 时仅生成并测试合成文件。原始计时记录位于 `verification/v3.5.2/chgcar_benchmark.json`。

- 最终全量测试：**1,481 项通过、78 个子测试通过、12 项跳过，无失败。** 跳过项需要未随包提供的其他私人样例；本次 CHGCAR 实际文件测试已运行通过。
- 新增识别和数值测试覆盖重命名、真 CUBE、普通 POSCAR 速度表、UTF-16、D 指数、PAW/自旋通道、超长行、异常和多余数据、取消操作及大量小增广块的有界读取。
- 两项 Qt 集成测试验证重命名后的后台读取、原子表、Field 数据集列表及通道切换。
- 独立复核包括 37 个随包文档对比、4,000 组数值块差分和 30,000 次缓冲区随机操作，未发现数据差异。
- 新构建的 v3.5.2 wheel 与最终源码逐文件一致，并从 wheel 读取本次实际 CHGCAR 及重命名副本，得到相同网格摘要。
- 原始测试 XML、最终性能记录及 wheel 核对结果位于 `verification/v3.5.2/`。

源码及重新构建的 wheel 均包含本次修复。使用源码可运行 `start_windows.bat` 或已有环境中的 `python -m lele`。已有 Windows EXE 需要用本版源码运行 `build_windows.bat` 重新生成。
