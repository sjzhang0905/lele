# LELE 1.7.0：恢复验证

日期：2026-10-27

## 范围与基线

以 v1.6.0 为基线重新实现 v1.4 / v1.5 的功能，保留真实扩胞。
未声称找回原源码或进行逐字节恢复；以功能、科学数值和实际 GUI/导出回归验收。

完整回归为 **222 项测试、72 个子测试通过**。包含既有启动、选择、坐标、频率、GIF、显示样式和扩胞用例。
1.7.0 wheel 实际构建并核对版本、MIT 许可及 Python 模块与当前源码一致。

## 科学数据

- 真实 `mol1.log`：51 原子、5 个 TD 跃迁。电、速度规范及磁跃迁偶极分表解析。
- 第一电跃迁矩为 `(-1.7040, -4.4103, -1.7487)` au，换算
  `(-4.33113595, -11.20986437, -4.44475202)` D；按能量与电偶极算得
  f=`2.1160596033`，与打印 `2.1160` 在取整精度内一致。速度规范打印 f=`2.0585` 单独保留。
- UV-Vis 主峰约 `364.7911 nm`；该文件永久偶极来自 SCF Density，不标为激发态永久偶极。
- 真实 `ts1.log`：134 原子、43 帧、396 个振动模式（1 个虚频）、3 条普通偶极记录。
  IR 使用 395 个正频模式；无打印 Raman 活性时不生成 Raman 曲线。
- Gaussian 最后帧能量显示约 `-6512706.08484241 kcal/mol`，从 ASE eV 仅在显示层换算。
  SIESTA 示例保持 eV；通用 ASE 格式保留软件标签以判断显示单位。
- 人工 CI 激发态永久偶极与 SCF/跃迁偶极分别选择。无 TD 上下文的 CI 密度不误标激发态。
  重复计算缺少跃迁矩时不沿用旧组，缺失 CSV 值与真实 0 分开。
- IR/Raman 虚频排除、缩放、Raman 激光与温度权重、两种线型面积/FWHM 和 UV 波长映射通过。

## GUI、结构与导出

- 实际三类偶极 PNG 按钮分别生成图片；Off 临时显示总箭头后恢复 Off。
  总箭头加分量为四支箭头。CSV 类型、计算组、态编号、分量、模长及强度回读通过。
- UV-Vis 原始跃迁导出为一行一个态，光谱 CSV 为 5000 个采样点，两个按钮分别验证。
- Qt 元素行单击/双击不展开，小三角正常展开；画布同步与刷新保持折叠状态。
- 真实 Ctrl+C/Ctrl+V 跨文档传递原子及显示设置；点击焦平面落点，目标晶胞保持，撤销恢复原能量和原子。
- Qt 矩形拖拽不进入相机旋转事件；投影中心、隐藏原子排除、追加选择及 Esc 退出通过。
- 线性三原子的遮挡长键去掉，三角环及手动恢复键保持。
- Boundary 单原子简单立方 0…2、0…2、0…1 为 18 个显示副本、33 条键，源结构仍 1 原子。
  副本编号、透明度、拾取、高亮、负范围和斜晶胞通过。PNG/GIF 使用重复显示范围。
- 扩胞保留原有测试；原生界面从硅的 8 原子生成 32 原子，Undo 回到 8 原子。
- GIF 原生 2× 超采样并 Lanczos 缩小到目标尺寸，跨动画采样共用调色板，静态背景颜色一致。
  抖色渐变误差检查、逐帧解码、帧时长、取消/失败不破坏文件和实时视角/播放恢复通过。
- 角落三字母绑定实际标记相机；保存默认目录与输入文件相同。
- 人工 Gaussian 两帧的实际能量曲线以 kcal/mol 显示，最高相对能量 `62.75094739`。

## 环境与限制

Linux、Python 3.12、PySide6 6.12、ASE 3.29、VTK 9.7.1 EGL、Pillow 12.3。
真实 Qt 控件与原生 VTK 离屏渲染用于验收；Windows EXE 未在此环境构建，
需运行 `build_windows.bat` 后验收 Windows 原生窗口。

公开截图仅使用包内人工示例，不附带用户 `mol1.log`、`ts1.log` 或相应结构图片。
光谱是打印数据的展宽模拟；跃迁与永久偶极不是同一物理量，振动预览不重新计算瞬时偶极。
Boundary 不重复体网格，真实扩胞不外推能量；成键过滤为几何显示规则，不是键级计算。
