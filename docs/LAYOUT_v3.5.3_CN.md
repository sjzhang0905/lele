# LELE 3.5.3 窄面板布局

## 本次修改

- 左侧每次启动使用原有可见最小宽度：295 个逻辑像素。仍可手动拖宽；窗口放大时新增空间分配给画布，已手动设置的侧栏宽度保持不变。
- 左侧与底部设置中的下拉框统一为 90 个逻辑像素，约为原最窄 Style 页下拉框宽度的三分之一，不再随整行拉长。展开列表按选项文字扩宽；鼠标悬停显示当前完整选项及原有说明。
- 水平滑杆最长 265 个逻辑像素，比侧栏最小宽度短 30 像素；标签和数字框占空间时，滑杆自动缩短。
- Style 页的三段帮助文字自动换行，最窄侧栏下不再产生横向滚动。
- 上述尺寸使用 Qt 逻辑像素，随系统显示缩放换算为实际屏幕像素。

## 检查

在 Linux 的 Qt offscreen 环境下，分别使用 Windows 和 Fusion 两种 Qt 样式检查了真实窗口构建、全部侧栏/底部标签、下拉列表、窗口缩放和分隔条拖动，并检查了布局截图。窗口宽度在 1200、1380、1920 之间切换时，初始侧栏保持 295；手动调到 400 后继续放大也保持 400。所有对应下拉框为 90，Field 滑杆上限为 265。没有进行 Windows 原生桌面实机验证。

完整回归：1481 项通过，12 项跳过，78 项子测试通过；包括提供的 CHGCAR 实例读取检查。发行 wheel 中的 131 个 Python 模块与源码逐字节一致。

本版保留 3.5.1 的启动、大 CUBE、长 AIMD 读取优化，以及 3.5.2 的重命名 CHGCAR 识别与读取加速。
