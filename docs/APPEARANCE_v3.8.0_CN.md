# v3.8.0 默认外观和灯光

- 默认 Ball and stick 原子尺寸由 50 调为 47，键粗细由 7 调为 6，分别对应界面三个和一个最小刻度。其他有独立参数的风格预设保留自己的尺寸。
- Default 配色在 v3.7.0 颜色基础上额外混入 15% 白色，每次根据固定基色计算，不会随重绘逐次变白。手动指定的元素颜色、单个原子颜色保持原值。
- 正等值面改用 VMD 的 lime：RGB (0.5, 0.9, 0.4)，8 位颜色 `#80E666`。
- 负等值面改用 VMD 的 cyan3：RGB (0, 0.76, 1)，8 位颜色 `#00C2FF`。这里使用的是 VMD 定义，不是同名的 X11 cyan3。
- “减小透明度”按提高不透明度处理，默认 opacity 从 0.65 提高到 0.90；正负面均可继续单独设置。
- 选中原子的绿色虚线圆环线宽从 3.5 增至 9，保持中空、相机朝向和不参与原子拾取。
- View → Lighting 提供四个不同方向的白色平行光，默认打开前两个。光源相对相机固定，避免旋转结构后前侧突然变暗。状态按文件保存，并随项目文件和图像导出保留。

VMD 颜色值、四盏灯方向及默认开关状态的来源：
https://www.ks.uiuc.edu/Research/vmd/doxygen/Scene_8C-source.html

仅采用颜色及方向数值事实；光源强度按 LELE 的 Glossy 材质设置为 0.85、0.45、0.45、0.35。
