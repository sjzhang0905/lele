# LELE 3.16.0 验证记录

2026-11-18，基于 LELE 3.15.0 源码包。

## 完整回归

Linux、Python 3.12.14、PySide6 6.12.0、VTK 9.7.2、ASE 3.29.0。完整回归通过 **2316 项**，另有 **78 项子测试**通过，**14 项**需额外的外部样例而跳过，失败与错误均为 0。完整运行耗时 147.45 秒。逐项结果见 [regression.xml](../verification/v3.16.0/regression.xml)，跳过原因见 [checks.json](../verification/v3.16.0/checks.json)。

## 片段旋转

测试用原始 124 原子模型 `01_NH2-Sn.xsf`，选中全局第 109 号原子所在的 16 原子片段。为对比有等值面的交互，给两版附加同一个 48 × 48 × 72 人工标量场。使用默认 Boundary，正负等值均为 0.035，视口为 740 × 520 像素，采用 EGL 和 Mesa llvmpipe 软件渲染。

每个版本预热后执行 3 轮，每轮 25 次水平位移，每次 3 个像素，每次处理 Qt 事件并实际绘制画面。首帧单独统计，其余共 72 帧。该数据反映本机测试场景的绘制和交互开销。

| 每帧耗时 | v3.15.0 | v3.16.0 |
|---|---:|---:|
| 首帧中位数，3 帧 | 49.01 ms | 17.87 ms |
| 连续旋转中位数，72 帧 | 49.74 ms | 17.03 ms |
| 连续旋转第 90 百分位 | 55.54 ms | 18.71 ms |

另用 Qt 事件与实际 VTK 点坐标核对了鼠标末次位移、连续事件合并、跨晶胞副本、键端点、标签、保留等值面和单次撤销。

## XSF 与显示设置

- 通过主窗口载入 `01_NH2-Sn.xsf` 和 `02_CO-Sn.xsf`，两者各 124 原子，三方向周期。逐项比对元素顺序、原子坐标、晶格矢量均与各自文件一致。
- 用非对称网格、倾斜晶胞和非零原点核对 XSF 数值顺序及等值面顶点的世界坐标。测试包含多通道、独立网格、分子、动画、周期端点、有限采样区域、文件截断、超限与取消。
- 随包示例在 ±0.035 生成两张等值面，总计 1000 个三角形。[示例渲染](../verification/v3.16.0/xsf_signed_surfaces.png)
- 检查 11 个新色值与旧版 118 种元素及 D 的默认色值均不同。另核对 Sibyl 参考表中全部 111 个元素在原子、元素色半键及图例上的实际取色。
- Qt 样式测得默认球棍模式三条滑杆的手柄中心与轨道中心重合。另验证两端数值、键盘微调、切换模式、切换文件与读取旧项目。[控件截图](../verification/v3.16.0/style_controls.png)
- 在 Linux Qt 环境验证灰色标题栏和窗口状态切换，另以模拟 Windows API 核对窗口句柄、标题栏和文字颜色参数。Windows 原生窗口的实际显示效果需实机核验。

## 发行包

源码通过 Python 编译检查。wheel 中的 183 个 Python 模块和 3 个资源与源码逐字节一致。安装到独立目标目录后，已验证主窗口初始化、默认滑杆和原始 XSF 结构及示例网格读取。
