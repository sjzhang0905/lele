# LELE 3.10.0 更新说明

发布日期：2026-11-11；基于 3.9.1，保留已有功能。

1. **Current selection** 改为只读、可复制的等宽纯文本，以空格对齐编号、元素、占据率、Cartesian / Direct 坐标及固定方向。没有表格控件或单元格边框。隐藏标签页延迟生成文本；切回时显示最新数据。大选区分块生成文本，生成期间显示 Updating…，持续播放停止后显示最新完整内容，不用旧坐标冒充当前值。
2. **启动自动最大化**。可以通过系统窗口按钮恢复普通大小。
3. **View → a / b / c** 从对应正晶矢方向观察结构，和 XYZ 一样切到正交投影并适配画布。方向依据当前显示的直接晶格矢量，支持斜晶胞及轨迹对齐后的显示旋转；不是倒易晶格法向。没有有效周期性晶胞时不可用。只改变视角，不旋转源坐标或晶胞。
4. **乐乐进度动画**：文件导入、通用计算/处理及 GIF 等导出共用进度窗口，在进度条上方使用欢迎页原有四帧走路图。位置随当前阶段的实际进度从左向右移动。无法确定总工作量时原地走动并显示忙碌进度条，不虚构百分比。保留原有延迟显示及取消行为。
5. **默认成键阈值 0.88**：Bonds 控件的滑块和数值框均从 0.88 开始，自动成键使用原参考距离的 88%，因此默认成键更少。已有项目显式保存的阈值继续生效；手动键及元素对规则保留各自设置。切回 Chemcraft 模型使用 0.88，Covalent radii 模型原有 1.18 默认值不变。

本版本不修改源结构文件中的坐标或原子顺序。
