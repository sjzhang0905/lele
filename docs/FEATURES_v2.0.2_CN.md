# LELE v2.0.2 修复与编辑行为

日期：2026-10-29（北京时间）。本版在 v2.0.1 源码上修复验收报告的 A1、A2、B1，
并让几何编辑保留原有键连接。交付为完整源码包；Windows EXE 需重新构建。

## 三项验收修复

| 项目 | 修复后的行为 |
|---|---|
| A1 非约化斜晶胞 | 短接触和最近周期像搜索先约化晶格；邻居搜索范围由晶胞与截断半径决定，不再依赖固定 ±1 周期像。返回平移仍以输入晶胞为基底。 |
| A2 轨迹显示对齐 | 原子、普通晶胞边框、Boundary 原子与边框使用同一个 `r @ R + t` 变换。源坐标、晶胞与导出结构保持原始值。 |
| B1 Windows 提示 | 缺少兼容 Python 时显示 `LELE needs 64-bit CPython 3.12 (preferred) or 3.11.`，去掉易过期的硬编码旧版本。 |

验收的斜晶胞示例现在得到 1 对短接触，距离 **0.474341649 Å**，周期像平移为
`(-2, 0, 0)`。另一最近像距离由错误的 8.040055970 Å 修正为 **1.594521872 Å**，
平移为 `(-4, 0, 0)`。

晶胞向量是方向与长度；显示对齐的平移单独加在边框端点上。Boundary 先在源晶胞中
构造完整副本，再统一施加显示变换。原点坐标轴继续标记显示世界坐标 `(0,0,0)`，
因此不会随晶胞平移；abc 轴方向跟随晶胞旋转。左下角坐标轴仍是方向指示器。

## 编辑时不自动成键、断键

首次几何编辑开始前，保存当前帧已有的共价键连接，后续编辑直接使用这份连接。

- **Alt＋鼠标中键拖动**及其他片段平移/旋转：即使靠近另一个片段也不会自动接上，
  原有键被拉长也不会自动断开；再次选择片段仍使用同一连接关系。
- **坐标表编辑、设置原点、轴/平面对齐**：保留编辑前连接。
- **删除原子**：仅移除该原子及涉及它的键；其余原子不会重新推断成键。
- **复制粘贴**：LELE 内部复制保存片段已有的内部连接，粘贴时不自动连到目标结构。
  从外部普通 XYZ 粘贴时，仅推断粘贴片段内部的初始连接。
- **真实扩胞**：复制源结构的周期连接，不因扩胞后的距离重新添加连接。
- **周期键**：保存其对应的原始周期像，移动和包裹坐标不自动改连另一周期像。
- **Ctrl+Z**：恢复坐标和键状态；编辑只影响当前帧。

打开新结构时仍按距离识别初始键。上述固定行为用于当前编辑会话；XYZ/POSCAR 等坐标
格式不保存 LELE 的会话键快照，重新打开导出的坐标文件时会进行初始识别。
Short contacts、距离测量和氢键候选仍根据当前几何更新，它们是分析结果。

## 明确修改键

1. 选中原子后按 **Ctrl+B**，沿用已有的成键/断键操作；选中两个原子时切换这对原子的键。
2. 如需根据编辑后的距离整体重新识别，选择 **Edit → Rebuild bonds from distances**。
   使用当前 **Bond cutoff ×**，保留已有手动添加/移除的覆盖规则，支持 **Ctrl+Z**。
   已固定连接的帧仅调整 cutoff 不会自动重新连接。

轨迹显示对齐开启时，几何/键编辑仍按原有规则禁用；关闭显示对齐后再编辑。
