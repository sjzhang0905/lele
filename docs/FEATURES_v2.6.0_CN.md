# LELE v2.6.0 使用说明

## Bond cutoff

在 **Style → Bond cutoff ×** 调整滑块，或在旁边的数值框精确输入。
范围由 1.00–1.60 扩大为 **0.10–5.00**，默认仍为 1.18。
该参数是两种元素共价半径之和的倍率，**不是以 Å 为单位的距离**。

以前几何编辑会冻结键连接，之后移动 cutoff 滑块也不会改变这些连接。
现在明确调整 cutoff 会重新识别当前文件各帧的自动键，包括此前冻结的自动键；
Ctrl+B 手工添加/删除的普通键和 Ctrl+H 虚线氢键会保留。
普通几何编辑仍然保持既有连接，避免移动过程中自动断键或生出新键。

**Crystal → Pair rules** 中明确指定的元素对仍使用自己的最小/最大距离，
优先于全局倍率；如果只想改变这类键，请修改相应规则。
自动成键仍有原有的 6.5 Å 搜索距离保护；更长的特定元素对可使用 Pair rules 设置。

## 底部信息与画布

Atoms、Formula/Composition、electrons、Short contacts 和选择测量位于同一条底部信息行。
状态消息显示在左侧，过长时省略，鼠标悬停可查看全文。
省出的空间分配给结构画布；底部坐标表/结果区仍可以拖动分隔条调整。

## 直接输入键长、键角与二面角

依次选择原子后，右下角显示原子顺序、当前值与数值框：

| 选择顺序 | 测量 | 默认移动部分 |
| --- | --- | --- |
| A、B | A–B 距离，Å | B 及 B 侧相连的末端片段 |
| A、B、C | A–B–C 键角，°，B 是顶点 | C 及 C 侧片段，绕 B 旋转 |
| A、B、C、D | 二面角，°，B→C 是转轴 | D 所在的 C 侧片段，B、C 轴线保持不动 |

输入目标值，按 **Enter** 或 **Set** 应用。键长必须大于 0，键角范围 0–180°，
二面角范围 −180–180°。例如改变水分子的 H–O–H 角，按 **H1、O、H2** 的顺序选择。
开始输入时暂停轨迹播放，避免输入过程中切换帧。

片段内原子整体平移或旋转，内部距离保持不变；只有当前结构帧被修改。
程序先检查所有普通键（包括手工键），把目标关节暂时从连通图中移除，
再确定最后所选原子一侧能独立移动的片段。虚线氢键属于显示标注，不拖动另一分子。

如果存在环、另一条普通键路径连到固定的所选原子、多个周期像共同连接同一关节，
或片段属于无限周期成键网络，会弹窗说明原因，**不改变结构，也不产生半完成的编辑**。
独立的跨晶胞有限片段可以展开并移动，相关周期像平移随坐标更新。
测量沿用已有坐标表中的实际坐标，不自动把所选原子的距离替换为最短周期距离。

应用后可用 **Ctrl+Z** 撤销。非刚性结构编辑会清除该显示帧已经不适用的能量；
原始计算记录与其他帧保留。频率参考和开启轨迹显示对齐时，数值框用于读取测量，
需回到几何帧并关闭显示对齐后才能编辑。

## ORCA 长输出与加载进度

ORCA 等计算输出通过后台线程加载，小于 4 MiB 的输出也使用后台流程。
长加载约 0.35 秒后出现进度窗，显示文件名、当前阶段、**当前阶段的百分比**和总耗时。
阶段切换时百分比会重新开始；不是预计剩余时间。没有可计数总量的阶段显示活动进度条。

阶段包括读取文本、识别计算任务、解析几何/能量/轨道、整理结构、读取偶极/激发态等；
有频率、GOAT 或 SOC 数据时再解析相应部分。最后在主线程准备结构视图。
点击 **Cancel** 可取消解析，不会加入部分解析的文件；随后继续打开队列中的文件。

长优化输出减少了无关 SCF 数值行的正则匹配，坐标块批量转换，属性对应结构使用
源文件行号索引查找；避免随优化步数增长而重复反向遍历整个结果列表。
加载期间定期让出执行时间，使界面有机会处理绘制、取消与鼠标事件。
没有新增帧数上限，也不以抽帧换取速度；实际容量仍由原子数、文件内容和可用内存决定。

本包为更新后的完整源码。Windows 解压后用 `start_windows.bat` 启动；
已有独立 EXE 需要用本版源码重新运行 `build_windows.bat` 生成。
测试环境、数据一致性和速度结果见 [验证记录](VALIDATION_v2.6.0.md)。
