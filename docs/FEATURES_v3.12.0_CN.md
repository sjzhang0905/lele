# LELE 3.12.0 更新说明

## 多文件顺序

同时拖放多个文件，或在 Open 对话框中多选文件时，先整理整个批次，再逐个打开。Files 标签页顺序与打开顺序一致。

- Windows 使用 `StrCmpLogicalW` 的逻辑文件名排序。
- 数字按数值排序，例如 `file1`、`file2`、`file10`。
- 其他系统使用不区分大小写的自然数字排序。
- 文件名相同时，按父目录等信息确定顺序。
- 新的一批追加到已有文件后；同一批内重复出现的文件只打开一次。

## 拖入文件夹

可直接拖入一个或多个文件夹，同时也可混合拖入文件。

- 递归检查子文件夹，加载 LELE 支持的结构、计算输出、轨道和体数据文件。
- 跳过不支持的文件、子目录链接和 Windows 目录联接，避免循环遍历。
- 文件夹扫描与格式初筛在后台执行，有进度提示并可取消。
- 文件夹和其中的文件同时拖入时，同一实际文件只导入一次。
- 个别文件失败后继续加载其余文件，并汇总错误。
- `.lele` 项目文件需单独指定打开；文件夹自动发现不会打开项目文件，以免替换整个当前工作区。

## Convert all

入口：**File → Convert all…**。

选择一个输出文件夹，为每个已载入文件导出最后查看的结构帧：

| 当前结构 | 输出 |
|---|---|
| 非周期分子 | XYZ |
| 周期结构 | CIF |
| 没有结构的结果文件 | 跳过，并在结束时说明 |

导出当前结构数据，保留坐标编辑和原子顺序；隐藏原子仍保留。仅用于显示的相机角度、轨迹对齐和 Boundary 复制不改写结构坐标。当前文件若处于振动模式，结构导出使用振动参考结构。

周期结构的混合占据通过 CIF 保留。非周期混合占据转 XYZ 时，沿用最大占据元素的确认流程。

## Export PNG all

入口：**File → Export PNG all…**。

选择输出文件夹，并统一设置 PNG 分辨率与边缘平滑。每个文件使用各自最后查看的帧、视角、颜色、标签和场显示。

- 当前活动文件的振动相位和临时显示效果先直接截图保存。
- 无结构结果页跳过，避免误保存上一文件残留画布。
- 导出结束或取消后，恢复原先活动文件、帧、相机、选择及播放状态。
- 渲染在主线程执行，保留现有进度窗口和乐乐走路动画。

两种批量导出都使用源文件主名；同名或已有目标自动加 `_2`、`_3` 等后缀，不覆盖输入或已有输出。单个文件失败不阻止其余文件，结束时显示成功、跳过、失败数量。取消后保留已完成的输出。

## 视图跳变修复

定位到的原因：`vtkCamera.DeepCopy()` 复制了相机字段，但没有推进目标相机的修改时间。OpenGL 因此可能继续使用上一视角的缓存矩阵；下一次鼠标操作更新相机后才出现正确视图。

现在恢复相机后显式调用 `Modified()`，使缓存立即更新。另清理焦点丢失或切换文件时尚未结束的 VTK 拖拽状态，避免把旧拖拽延续到新文件。

点击 Files 中的文件标题会返回该文件最后查看的帧；点击具体几何帧仍打开明确选中的那一帧。
