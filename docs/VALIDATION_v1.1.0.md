# LELE 1.1.0 验证记录

日期：2026-10-27

## 本版内容

- Atoms 页按元素分组，提供单原子或批量显隐、颜色、透明度、标签、编号与自定义文字。
- 显示属性作用于当前帧，支持撤销、删除后重排，并应用于周期复制、连接键和点击拾取。
- 底部左右分栏，左边为紧凑坐标表及原有文本/信息标签页，右边留空。
- 窗口首次绘制后自动后台预加载，文件可排队等待就绪后打开。
- 程序标题、欢迎页、Python 包版本、Windows 启动提示与当前文档统一为 1.1.0。
- MIT 协议、邮箱、仓库地址和鹦鹉图标继续保留。
