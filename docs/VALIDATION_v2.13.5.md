# LELE v2.13.5 外观与高质量 PNG 导出

日期：2026-11-03。基于 v2.13.4 源码包修改。

## 外观调整

| 项目 | v2.13.4 | v2.13.5 |
| --- | --- | --- |
| 默认 Ball and stick 的 Bond thickness | 9 | **7** |
| Default 配色下 Ball and stick 的 H 显示半径 | 0.155 | **0.17825（增加 15%）** |
| Default 元素色 | 原色混入 10% 白色 | **在当前颜色上再混入 5% 白色** |

颜色逐级按 8 位 RGB 四舍五入：先执行上一版的 10% 混白，再对所得颜色混入 5% 白色，累计相当于原色混入约 14.5% 白色。例如 H 为 `#D3D3D3`，C 为 `#9E9E9E`，O 为 `#E92525`。

原子、按元素着色的键、元素配色入口及图例继续使用同一颜色。H 的显示半径在原子球、标签位置、拾取范围、选择轮廓和图例之间保持一致。它是显示参数调整；结构坐标、成键距离表及 VESTA Space filling 半径保持原有定义。用户明确保存的颜色和显示参数仍按其设置恢复。

## 如何保存更清晰的画布图片

使用 **File → Save PNG… / Ctrl+S**，选择保存路径后，进入 **PNG image quality**：

1. 选择画布的 **1× / 2× / 3× / 4×** 输出，或直接填写自定义宽度。
2. 高度跟随画布比例计算，避免图像拉伸。
3. 默认采用 **3 倍输出**，并勾选 **Smooth edges**。
4. 确认 Save，保存为无损 PNG。

Smooth edges 使用额外采样和 Lanczos 缩小，同时临时提高球面、键管和箭头的网格精度。三维标签、坐标轴文字和箭头注释跟随输出分辨率缩放；二维状态文字使用其原有的分块缩放方式。保存结束后恢复原始网格、字体、相机、画布大小和播放状态。取消选项或保存失败不会覆盖已有图片。

输出单边上限为 8192 px，并检查中间渲染像素量；过大的设置会提示降低宽度或关闭平滑选项。PNG 写入 300 dpi 打印元数据；实际细节提升来自更高像素分辨率和渲染采样。
