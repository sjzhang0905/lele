# LELE 3.2.1：波函数与体数据

- **Gaussian FCHK/FCH**：读取几何、能量、轨道能级和占据；当文件包含受支持的 s、p、d、f 高斯基组与分子轨道系数时，可生成轨道等值面。
- **Molden**：读取几何、振动（如有）、轨道能级、占据与受支持的基组和系数；支持生成轨道等值面。未提供数据或基组类型不受支持时会说明，而不是推测。
- **ORCA GBW**：通过用户本机安装的匹配版本 `orca_2mkl` 转换为 Molden 后读取。将该工具放在 PATH，或设置 `LELE_ORCA_2MKL` 指向工具的完整路径；原 GBW 不会被修改。若未找到转换器且同目录存在同名 ORCA 输出文件，可读取其结构与能级，并明确标记来自输出文件而非 GBW；两者是否属于同一次计算仍须自行确认。
- **CUBE/CUB**：支持结构、多个网格或轨道数据集、倾斜网格和等值面。
- **VASP 网格**：支持 CHGCAR、CHG、PARCHG、AECCAR0/1/2、ELFCAR 和 LOCPOT，以及文件中存在的多个通道。电荷密度转换为 e/Å³；ELF 为无量纲，LOCPOT 为 eV。PARCHG 的物理含义取决于生成它的 VASP 设置。
- **WAVECAR**：读取自旋、k 点、能带能量及占据数。WAVECAR 不含原子坐标；可从同目录晶格匹配的 POSCAR、CONTCAR 或无歧义的 OUTCAR 显示结构，但晶格匹配本身不能证明文件必然来自同一次计算。对于通过布局校验的标准复数标量 WAVECAR，可以选择自旋、k 点、能带，显示单态伪波函数的实部、虚部或 |ψ|² 等值面；Gamma-only 半存储和 SOC/自旋量子态不支持。|ψ|² 不含 PAW 原子内补偿，也不等同于总电荷密度；实虚部取决于任意整体相位。

在 Field 区选择 Dataset 和正负等值面，调整等值面数值及透明度。对于带有受支持分子轨道系数的 FCHK/Molden，选择 Molecular orbital 和 Grid spacing，点击 Calculate orbital grid。网格求值只使用已有波函数，并不重新运行量子化学计算；修改结构后需重新打开源文件再计算轨道。数据过大、损坏或缺少所需信息时，程序会提示。当前体数据读取默认总上限为 6400 万标量值，实际内存开销还取决于数据集数量与显示设置。

GBW 需要本机 ORCA 工具；WAVECAR 依赖原文件的部分功能不保证在移动工程文件后仍可用。不同程序和版本的格式变体很多，建议用实际输出文件核对结构、轨道相位和数值。
