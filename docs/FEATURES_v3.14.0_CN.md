# LELE 3.14.0 更新说明

## ORCA index 只作为原子标签

仅在 **Label / Atom labels** 的标签模式中提供从 0 开始的 ORCA 编号。Coordinates (editable)、Current selection、Atoms 列表、Atom appearance 的选择说明、旋转窗口、编号输入和分析表格统一使用原有从 1 开始的编号。Atom appearance 的 **Label** 下拉菜单仍可给选中原子设置 ORCA 标签。

选择表达式使用 `index`，例如 `index 1, 3-8`；本版不再提供 `orca` 关键字。距离和元素表达式不变，例如 `element O and distance > 2 and distance < 5`。Help → Atom selection syntax 已同步更新。界面生成的扫描坐标说明也转为从 1 开始；ORCA 文件原文和解析器内部索引不改写。

## 实时绕轴旋转

按顺序选择轴上的两个原子，打开 **Rotate about selected axis**。Rotation angle 下新增滑杆，范围 −180°～180°，步长 0.1°；数值框保留更大角度范围和精度。拖动时数值框与画布同步，预览始终相对于打开窗口时的结构，不累积拖动误差。

点击 **Rotate** 才写入结构，并产生一次撤销记录；**Cancel** 或关闭窗口不修改原结构。预览期间仍可旋转相机、缩放或调整外观。若切换文件/帧，或改变选择、源坐标、成键等旋转依据，原预览失效，需重新打开。四原子二面角编辑同样支持预览。

## 原子和键的大小

- 默认 Atom size 从 47 调为 45，Bond thickness 从 6 调为 5；默认成键阈值仍为 0.88。
- 选中原子后，在 **Atoms → Atom appearance → Size scale** 输入独立缩放倍数。`1.00` 为当前样式的正常大小，`0.80` 缩小，`1.20` 放大；范围 0.05～10.00。
- 该倍数只修改选中原子的大小。多选可统一设置，支持撤销、项目保存、Boundary、副本扩胞及图片导出。
- 已保存项目中的显式全局大小设置保持原值。

## 左侧菜单布局

File / Edit / View / Analysis / Help 移到左侧标签页上方，宽度跟随左侧栏。画布向上延伸，使用右侧原本被菜单栏占据的空间。

## 两侧交替复制和原点

**Boundary** 只增加显示副本，源原子数量、坐标和晶胞不变。**Build supercell** 则真正增加原子，并按倍数扩大晶胞，可撤销。

两者现在都提供按每个晶轴 `0、+1、−1、+2、−2…` 交替复制的模式，默认保持原结构坐标。倍数包含原晶胞，例如：

| 晶胞数 | 沿单个轴的平移编号 |
|---|---|
| 1 | 0 |
| 2 | 0、+1 |
| 3 | 0、+1、−1 |
| 4 | 0、+1、−1、+2 |
| 5 | 0、+1、−1、+2、−2 |

各轴独立组合，原晶胞的原子保持在最前。世界坐标原点不平移；生成的负方向副本可以保留负坐标，晶胞轮廓相应覆盖负方向。相机也保持当前位置，需要查看所有新副本时可缩小视图或执行 Fit。

Boundary 可切到 **Manual cell ranges** 指定范围；Build supercell 保留 **Forward + only (legacy)**，并可选择先将原子折回原晶胞。旧项目缺少新设置时沿用原有 Boundary 显示方式。

真实扩胞仍会清除不再适用于新结构的源能量等信息，附带的体数据会解除关联；Undo 恢复。导出遵循各格式原有约定，例如周期性格式可将等价分数坐标折回晶胞，而 XYZ 保留笛卡尔坐标。
