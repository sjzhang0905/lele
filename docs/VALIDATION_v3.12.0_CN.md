## 本次重点验证

1. **批量导入**：自然数字排序、Windows 原生比较器分派、文件名同值的稳定顺序、递归目录扫描、重叠目录去重、链接循环规避、取消、后台发现与顺序加载，以及新请求排队。拖放回调保持不访问文件系统。
2. **格式筛选**：不整体读入大文件；对含糊后缀做有限内容探测。额外覆盖真实最小 ORCA `.molden.input`、大写后缀和无关 `.input` 文本。自动扫描不打开会替换工作区的 `.lele` 项目。
3. **批量结构转换**：使用各文件记住的帧，分子输出 XYZ、周期结构输出 CIF；读回比较坐标与原子数。隐藏原子仍保留，振动模式使用参考结构。验证同名、大小写同名、原文件保护、已存在输出保护、写入中途失败、取消和失败后继续。
4. **批量 PNG**：两个不同视角和标签的文件，逐个导出与批量导出逐像素一致；导出后恢复的当前画布也逐像素一致。验证失败、取消、振动相位、临时平面、选择、结果页与批量菜单恢复。
5. **视角跳变**：直接读取 OpenGL framebuffer，避免截图过滤器掩盖缓存问题。四种正交/透视切换组合均验证修复后立即恢复相同图像；另验证首个鼠标移动、失焦拖拽结束及文件切换。对比图见 `verification/v3.12.0/camera_restore_before_after.png`。
6. **帧记忆**：新导入仍默认最后一个结构帧；点击文件标题返回最后查看的帧；点击具体帧打开指定帧。每个文件相机独立保留。
