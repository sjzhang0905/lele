# LELE 3.5.7：CIF 空间群与拖放修复

日期：2026-11-10

## CIF 空间群名称

部分 CIF 将螺旋轴写为 `2(1)` 或 `2_1`。旧版直接交给 ASE 空间群数据库，可能报 `invalid spacegroup P2(1)/c`。

本版在内存中将合法螺旋轴写法规范为数据库可识别的名称，例如 `P2(1)/c` → `P21/c`。该步骤只处理名称的排版差异，不改晶胞、坐标、原点、setting、占据率或显式对称操作；也不将未知空间群强行降为 P1。

用户提供的 `DPA-1044209.cif` 已验证：

- 空间群：P21/c，No. 14。
- 非对称单元：22 个原子；按文件中的 4 条操作展开为 88 个原子，即 C52H36。
- 晶胞：a=17.973 Å，b=7.352 Å，c=6.245 Å；α=90°，β=90.646°，γ=90°。
- 与独立手工转录的对称操作展开比较，最大分数坐标差约 1.11×10⁻¹⁶。
- 原 CIF 的字节和 SHA-256 保持不变。

## 拖放和读入失败

旧版在原生拖放回调内直接开始读文件。读入过程的嵌套事件循环，以及失败后的阻塞式错误框，会延迟拖放返回，使 Windows 拖动源窗口保持等待。

本版拖放回调只接收本地路径并安排后续处理，先返回，再进行文件检查、读取和显示。导入采用复制语义，不移动或删除源文件；仅允许移动的拖动来源会被拒绝。

CIF 即使文件很小，也使用后台读取。失败时先释放进度框和读入状态，再显示非模态错误提示；剩余文件继续按队列处理，不必先关闭错误框。导入任务交接期间的新请求会追加到队尾；同步小文件读取的嵌套事件循环不会重入解析。取消和关闭窗口时不会把未完成结果加入会话。

## 验证范围

测试包含空间群别名、显式操作、混合占据、非法空间群拒绝、拖放回调立即返回、失败后的队列继续、取消和关闭等场景。验证记录保存在 `verification/v3.5.7/`。

实际 CIF 还通过了 Qt 拖放到文档、结构场景和坐标表的完整链路验证：拖放回调先返回，文件列表新增 1 项，坐标表含 88 行，无错误提示。该项使用无屏幕测试画布，跳过原生 OpenGL Render 调用。

运行环境为 Linux 下的 Qt/VTK，验证了原生拖放回调的返回边界及错误框的非模态属性；未直接运行 Windows Explorer。用户原始 CIF 不随发布包分发，可通过环境变量 `LELE_DPA_CIF_EXAMPLE` 复跑实际样例测试。

完整回归：**1542 passed、13 skipped、78 subtests passed**，无失败或错误。
