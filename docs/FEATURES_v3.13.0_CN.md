# LELE 3.13.0 更新说明

## Current selection

右下 Current selection 不再显示 ORCA index 列，继续保留从 1 开始的 Index 和原有对齐纯文本信息、一键复制坐标。其他原子表、原子标签和编号选择中的 ORCA index 保留。

## 选择表达式

在右下 **Atoms selection → Selection expression** 输入后，按 Enter 或点击 **Apply expression**。成功时替换当前选择，可按 Ctrl+Z 撤销；输入错误或取消时原选择不变。表达式和下面的编号输入行是两种独立选择方式。

完整语法在 **Help → Atom selection syntax…**，输入框旁的 **Syntax…** 也可打开。

| 表达式 | 含义 |
|---|---|
| `element O` | 所有氧原子 |
| `element C H` | 所有碳、氢原子 |
| `element O and within 3.5 of selected` | 距离当前选中原子的最近距离不超过 3.5 Å 的氧 |
| `element H and distance > 2 and distance < 5` | 最近距离严格大于 2 Å、严格小于 5 Å 的氢 |
| `not selected and within 3 of selected` | 3 Å 内的其他原子，不包含原先选中的原子 |
| `(element O or element N) and not index 1-4` | 氧或氮，但排除全局编号 1–4 |
| `index 1, 3-8` | 全局编号，从 1 开始 |
| `orca 0, 2-7` | ORCA 编号，从 0 开始 |
| `index >= 5 and orca < 10` | 对编号作比较 |
| `all` / `none` / `selected` | 全部 / 清空 / 当前选择 |

- 支持 `and`、`or`、`not` 和括号；优先级依次为 `not`、`and`、`or`。
- 比较支持 `<`、`<=`、`>`、`>=`、`=`、`==`、`!=`。
- 元素与关键字不区分大小写，编号范围包含端点，可用 `3-8` 或 `3 to 8`。
- 距离均为 Å，以按下 Apply 时的原子选择为固定参考；多个参考原子取最近距离。参考原子自身距离为 0。距离表达式必须先选至少一个参考原子。
- 周期体系使用最小周期像距离，包括斜晶胞与部分周期方向；显示的 Boundary 复制不新增源原子编号。
- 混合占据位置可按任一正占据元素选中，同一位置只选一次。
- 这是明确列出的 VMD 风格语法子集，不运行脚本，也不声称兼容完整 VMD 语言。
- 非周期距离用空间索引；周期距离分块计算，避免一次分配完整距离矩阵。极大候选集和参考集仍可能耗时，可取消。

## 非模态置顶弹窗

帮助、设置、编辑参数、文件/颜色选择和结果分析等功能弹窗允许继续旋转画布、选择原子和操作主界面。弹窗保持置顶；帮助改为可滚动窗口。文件/颜色选择使用 Qt 窗口，避免系统原生模态窗口锁住主界面。

已经打开的编辑窗口绑定打开时的源结构与选择。若期间切换文件/帧、修改几何或改变相关原子选择，旧窗口的应用会被取消并显示 Source changed，需为当前对象重新打开。相机旋转、缩放和普通外观调整不会触发这个保护。父窗口关闭、嵌套编辑目标被删除时，不再继续应用已经失效的编辑。

真正执行读取、计算、结构处理或写出时的进度窗口保留并发操作保护；这些执行阶段不开放可能改写输入或重入渲染的操作。

## 欢迎页后自动预加载

启动时先完成可见欢迎页的绘制，再自动进行：

1. 后台线程加载常用文件读取器、ASE 格式注册/邻居搜索、SciPy 空间分析和图片依赖。
2. 界面线程初始化隐藏 VTK 上下文，预热原子、键、标签、坐标轴及等值面渲染。
3. 状态栏显示 Ready；此前选择的文件会自动继续打开。

预热无需用户打开结构来触发，不增加虚构文档，不替换欢迎页，也不覆盖欢迎页中已调整的外观设置。Qt/VTK 对象和渲染仍在界面线程创建，较重的模块导入在后台线程完成。

本次新进程对比测试显示，首次结构打开的主要依赖已在 Ready 前加载。完整测量条件、数值和局限见本版验证记录；这不是 Windows 重启且清空磁盘缓存的实测。若仍运行旧 EXE，须重新运行 `build_windows.bat` 构建新版程序。
