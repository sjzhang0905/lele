# ChemView Studio v0.9.0 — 拟合平面、反选与原子删除

日期：2026-10-24

## 自动拟合平面

在三维视图或坐标表中选中至少三个非共线原子，自动显示半透明蓝色平面。在左侧 `Edit → Best-fit selection plane` 中可查看平面方程、均方根距离（RMS）及最大偏差，或取消 `Show plane for 3+ selected atoms` 隐藏平面。

拟合使用等权重的正交最小二乘法（中心化坐标的 SVD）。三个非共线原子定义精确平面；更多原子不完全共面时，得到使垂直距离平方和最小的平面。共线选区会提示无法确定唯一平面，不生成错误的平面。

周期结构默认勾选 `Use nearest periodic images`：以第一个选中原子为锚点，选取其余原子的最近周期镜像。若要按照屏幕中原始坐标所在的晶胞拟合，取消勾选。该选项不改动原子坐标；对较大选区，最近镜像代表的局部表面可能与输入晶胞中跨越较远的表面不同，应按所需表面选择此选项。

## 将平面对齐到 XY

点击 `Align fitted plane to XY`，将拟合平面的法向量旋转到 +Z，得到平行于 XY 的平面。对分子和周期结构均适用。

- 这是完整结构的刚性旋转：全部原子、晶胞向量及附带体数据的网格方向同步旋转，保持原子间距离、周期最小镜像距离及晶胞形状。
- 默认勾选 `Place fitted plane at z = 0`，旋转后再沿 Z 平移，使拟合平面位于 z=0。取消勾选时只使用旋转矩阵，不进行平移。
- 原子本来不完全共面时，保留各原子偏离平面的距离；此功能不会把结构压平。
- 变换使用行向量约定 `r_new = r_old @ R.T + translation`。旋转矩阵和位移可在底部 `Results / info` 查看。
- 与原有两原子 XYZ/abc 对齐功能不同，本功能会同步旋转晶胞；原有两原子对齐行为保持原定义。
- `Ctrl+Z` 恢复旋转前的原子、晶胞、网格和选区；导出结构会写出实际变换后的坐标与晶胞。

## 反向选择

左侧 `Edit` 中点击 `Invert selection`，或按 `Ctrl+I`，选择当前帧中所有尚未选中的原子。空选区反选为全选，全选反选为空选区。周期预览中的复制原子沿用原始原子编号，不会作为额外原子参与反选。

## 删除原子

选中原子后按 `Delete`，或点击 `Edit → Delete selected atoms`。

- 仅删除当前帧中的选中原子，并更新坐标表、选择高亮、编号、POSCAR 元素分组及保留下来的手工键索引。
- 可删除全部原子，留下空帧；此时仍可切换轨迹帧，或用 `Ctrl+Z` 恢复。
- `Ctrl+Z` 可恢复删除前的原子、手工键及选区。
- 在坐标、数值或文本输入框中编辑内容时，`Delete` 继续用于删除文字，不会同时删除原子。
- 原计算能量不再适用于删减后的结构，因此当前帧不再显示该能量。原结构的体数据会被解除关联，撤销后恢复。
- 原始输入文件保留；需要保存编辑结果时使用 `Export structure`。

## 使用

1. 解压本源码包到新目录，运行 `start_windows.bat`；核对标题 `ChemView Studio 0.9.0`。
2. 可打开 `examples/selection_plane_demo.POSCAR`，选中前四个 Cu 原子，观察自动拟合平面，再到 `Edit` 中执行平面对齐。
3. 按 `Ctrl+I` 反选到剩余的 O 原子，再按 `Delete` 删除，最后按 `Ctrl+Z` 恢复。
4. 使用 EXE 时需重新执行 `build_windows.bat`，启动新生成的 `dist\ChemViewStudio\ChemViewStudio.exe`。

本包为完整源码包，保留 v0.8.1 的显示风格修复，不含已编译的 Windows EXE。
