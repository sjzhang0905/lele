# ChemView Studio v0.8.1 — 验收问题修复

日期：2026-10-23

## 修复内容

1. **自定义元素颜色完整保存与恢复**
   - 元素颜色编辑现在自动进入 `Custom (manual)`。
   - 元素颜色随命名预设写入 `style_presets.json`，重新加载预设和重新启动后的读取均可恢复。
   - 切换内置预设恢复该预设的默认配色；切回 Custom 可恢复最后的手动设置。
   - 各预设保存独立的颜色副本，不再修改全局元素默认颜色。
   - v0.8.0 的预设文件仍可读取，缺少颜色字段时使用默认颜色。旧版本从未写入文件的颜色无法补回，需重新编辑并保存一次。
2. **化学键开关对周期片段生效**
   - `Display bonds` 同时控制普通化学键和 Ctrl+G 周期片段预览的化学键。
   - 球棍、棍状和线框模式均遵守该开关；空间填充模式仍不显示共价键。
   - 此开关仅改变绘制，不清除手工键、不改变片段连通关系或原始坐标。
3. **线框模式保留原子标签**
   - 切换 `Thin wireframe` 后继续显示已开启的原子标签，并保留字体、字号和颜色。
   - 标签放置使用线框的实际细线半径，避免按不可见原子球的半径偏移。
   - 标签模式为 `None` 时仍不显示标签。

## Windows 使用

1. 解压到新目录，运行 `start_windows.bat`。
2. 确认窗口标题包含 `ChemView Studio 0.8.1`。
3. 若使用 EXE，重新运行 `build_windows.bat`，再启动新生成的 `dist\ChemViewStudio\ChemViewStudio.exe`。
4. 可依次检查：编辑氧颜色并保存预设，重启后加载；打开跨边界水分子示例并执行 Ctrl+G，关闭 `Display bonds`；开启标签后切换 `Thin wireframe`。
