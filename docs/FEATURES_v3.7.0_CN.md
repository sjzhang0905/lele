## 等值面矩形贯穿隐藏

1. 加载 CUBE、CHGCAR 等场文件并显示等值面。
2. 在底部 **Field** 勾选 **Rectangle hide isosurfaces (through depth)**。
3. 在画布上拖出矩形，松开鼠标即隐藏框内贯穿整个深度的等值面部分。
4. 可以连续画多个矩形。点击 **Undo last surface hide** 撤销最后一次隐藏；点击 **Restore all hidden surfaces** 恢复全部。

隐藏模式下，Ctrl+Z 撤销最后一次等值面隐藏，Esc 退出隐藏模式。Delete 不会误删已选原子。原子框选和等值面隐藏是两个互斥的鼠标模式。

隐藏针对所有当前显示的等值面，包括正负等值面、自定义层及 Boundary 扩展出的副本。即使一个网格三角形跨越矩形边缘，也会切掉矩形内部的部分，而不是必须整块选中才能隐藏。该功能只隐藏三维等值面，不隐藏原子、键或二维切片。

隐藏区域保存在结构坐标中，旋转相机后不会跟着屏幕移动；重新调整等值面数值后，隐藏区域仍生效。不同文件保存各自的隐藏区域，新的文件不会继承其他文件的区域。保存 `.lele` 项目可以保留这些显示设置。

## 统一晶体工具入口

原 View 中的 **Crystal tools… / Lattice planes / cuts… / Coordination polyhedra…** 三个重复入口，合并为 **Edit → Crystal tools…**。

窗口内仍保留 **HKL planes、Polyhedra、Pair rules** 三个标签。原有晶面裁剪、配位多面体、元素对规则保持可用。

## HKL 面和拟合面的二维场切片

### 三维等值面与二维切面独立控制

底部 **Field → Isosurface signs** 新增 **None**。该选项隐藏全部三维等值面，包括显式定义的自定义层，但场数据仍然加载，可以用于切片、切换 Dataset 和导出。

二维切面的数值来自当前 **Dataset**，通过原始三维网格做三线性插值。它绘制的是指定平面上的场数值，不是三维等值面的边缘线。

### 使用 HKL 面

1. 加载周期结构及相应场数据。
2. 在 **Field → Isosurface signs** 选择 **None**（如果希望只看二维切片）。
3. 打开 **Edit → Crystal tools… → HKL planes**，点击 **New**。
4. 设置 `(h k l)` 和 **Position**；新建面的 **Keep region** 默认为 **Show only**，不会自动切掉原子。
5. 保持 **Color plane by active field** 开启，点击 **Apply planes**。
6. **View normal to (hkl)** 可以将视线对准晶面法向，方便查看类似二维图的效果。

完整晶面与当前晶胞 / Boundary 显示范围相交。对于有限 CUBE 网格，着色范围限制在实际有数据的区域，不在网格外推测数值。周期场按其自身网格周期采样，可以显示跨晶胞切面。

### 使用 Fit selected plane

选择至少三个不共线原子，执行 **Edit → Fit selected plane**。显示的平面扩展到完整范围：周期结构使用当前晶胞 / Boundary 范围；孤立体系有场数据时使用网格范围，否则使用整个结构的投影范围。

拟合面的透明度、场着色、色标和等高线选项位于侧栏 **Edit → Best-fit selection plane** 区域。拟合依据仍是当前原子选择；改变选择、所选坐标或帧后需要重新拟合。拟合面不会将原子强行拉到平面上。

### 显示参数

| 控件 | 作用 |
| --- | --- |
| Plane opacity | 平面及场切片的不透明度，0 完全隐藏，1 完全不透明 |
| Color plane by active field | 开启场着色；关闭后显示普通单色平面 |
| Slice colors | Auto、Blue-white-red、Viridis |
| Fixed slice color range | 手动固定色标上下限，便于比较多张图 |
| Slice contour lines | 在彩色切面上叠加等高线 |
| Slice color scale | 显示包含场名称和单位的色标 |
| Slice resolution | 每个平面方向的最大采样数，默认 256，可设置 16–1024 |

Auto 模式对识别为 ELF 的数据使用 Viridis 和 0–1 范围；其他场默认使用正负对称的蓝白红色标。差分电荷密度需要预先生成差分网格；本版本不进行多个电荷密度文件相减。

高分辨率网格的切片预览可能受 **Slice resolution** 限制，界面会提示；提高该值可以增加细节。它只影响显示采样，不改写原始场数据。画布上的切面、色标和等高线可随主窗口 **Save PNG…** 一起导出。

原有 **Field → Planar slice…** 独立二维绘图窗口仍然保留，用于三组网格平行切片及完整采样 CSV 导出。

## 从已加载的 VASP 输出构建 NEB 路径

### 选择图像与能量

1. 将同一 NEB 路径中初态、中间图像和终态的 VASP 输出文件加载到 LELE。
2. 打开 **Analysis → VASP NEB from loaded outputs…**。
3. 使用 Ctrl / Shift 一次选中多个已加载文件，然后点击 **Use selected only**；也可逐个勾选。勾选的文件从上到下就是路径顺序；高亮需要移动的行，用 **Up、Down** 调整，也可按路径数字重新排序。
4. 默认使用每个文件最后一个已解析离子构型对应的 **E0 (σ→0)**。也可将整条路径统一改为 **Free energy TOTEN**。
5. 点击 **Build NEB path**。

所选文件必须具有相同原子数、元素顺序、周期性和晶胞。每张图像必须含所选能量类型，不会混用 E0 和 TOTEN，也不会从较早构型偷偷补上缺失的末帧能量。已编辑而导致能量失效的输出需要重新加载。

同元素原子的身份由输入中的原子顺序确定；相同元素内部若曾重新排序，必须先由用户纠正。程序不会根据距离擅自重新配对原子。

### 路径曲线

**Energy path** 标签显示相对于初态的能量曲线、各图像数值表、最高采样图像、正向和反向的采样能垒，以及终态与初态能差。

横轴可选择图像编号，或沿路径累计的所有原子 Cartesian 位移范数（Å）。周期体系对相邻图像使用最小镜像位移，支持斜晶胞。图像之间的线段仅连接已计算的数据，不代表额外计算了过渡态，也不单凭加载文件就判断 NEB 已收敛。

曲线工具栏可保存图片；**Export path CSV…** 导出精确数值、文件路径及对应源帧信息。

### 毛毛虫图

**Caterpillar** 标签将指定原子在每张图像中的位置一起显示，其余原子只显示一次。

- **Migrating atom indices**：填写原子编号或范围，例如 `1, 2, 5-8`。若主窗口当前选择来自该路径，则优先使用该选择；否则默认选中沿路径累计位移最大的一个原子。
- **Fixed surrounding structure**：选择周围结构使用哪张图像，默认初态。
- **Color by image**：按路径顺序着色。
- **Connect trajectory positions**：连接相邻图像中的同一原子，细线仅表示轨迹。
- **Label image numbers**：显示原子及图像编号。
- **Use main view direction**：沿用主画布的观察方向。
- **Save caterpillar PNG…**：导出当前毛毛虫图。

各帧复制出的迁移原子之间不会自动建立化学键。周围原子的轻微弛豫通过所选参考帧统一表示。周期轨迹逐段展开，避免因跨越晶胞边界形成横贯整个晶胞的假轨迹；仅凭离散图像不能还原超出最小镜像假设的长距离跳跃。

## 数据与显示的关系

本次新增的隐藏、晶面显示、二维切片和 NEB 展示均不改写输入文件中的计算数据。导出的 CUBE 仍是完整原始场；`.lele` 项目保存可恢复的显示设置。毛毛虫图是多图像叠加的展示构型，不作为真实计算结构输出。

ELFCAR 仍需保留文件名中的 `ELFCAR` 标识，以保证按 ELF 原生无量纲数值读取。没有可区分标识的 VASP 网格无法仅凭通用网格内容可靠确定其物理量。

验证环境为 Linux 下的 Qt / VTK 离屏运行；Windows 原生桌面尚未进行本轮实机操作验收。VASP NEB 使用覆盖解析和界面流程的合成输出测试，未代替具体用户 NEB 文件验收。
