## 九项需求覆盖

1. 两次不按修饰键的框选累加，重复框选不增加无效历史；两次 Ctrl+Z 依次恢复前一个选区和最初状态。
   选区与几何删除混合后，撤销依次恢复几何和选区，不损坏坐标。
2. Gaussian 限制性与非限制性轨道表：核对轨道序号、占据、Hartree→eV、α/β 通道及各自能隙。
   ORCA 保留从 0 起的编号，直接读取打印的 eV 列。测试无空轨道、负能量空轨道、简并 HOMO、
   ROHF 仅打印 alpha 通道时不误标双占据；真实打开文件自动弹出 eV 窗口。
3. 实际 VTK 抓图比较：框选外框可见、由分段虚线组成，中心像素与无框状态一致，隐藏后恢复原图。
   外框使用独立渲染层，不依赖 Qt 子控件覆盖三维窗口。
4. 原生 Ctrl+A 全选原子；输入框 Ctrl+A 仍选文字，选区撤销不改坐标。
5. 原子透明度与键采用本次更快衰减规则：键不透明度为较低端点不透明度的平方；
   普通键、周期显示、氢键、隐藏端点、完全透明端点和撤销回归通过。
6. 同文件兼容帧及振动参考构型同步显示属性，其他文件保持不变；坐标、成键不传播。
   验证先撤销几何导致 Frame 对象替换后，再撤销显示仍能恢复全部帧。
7. 计算总览分别显示两段的 charge/multiplicity、方法、基组、正常终止及收敛数据；
   缺失和未结束输出不使用虚构默认值。普通几何文件提供基本结构/可用能量信息。
8. 使用真正的 Matplotlib 鼠标点击事件，核对能量曲线和最大/RMS 曲线均跳转到对应几何帧。
   扫描终点筛选正确；无对应几何的计算段不会借用其他段的曲线。Qt 实际窗口抓图也纳入回归。
9. Gaussian 的正/反向组成、alpha/beta、带符号系数与 ORCA 打印权重分别保存；
   表格和 CSV 中的完整 JSON 回读保持一致。未打印强度保持缺失，不替换成 0。

## 环境与范围

Linux、Python 3.12.14、PySide6 6.12.0、VTK 9.7.1 EGL、ASE 3.29.0、NumPy 2.3.5、
SciPy 1.17.0、pytest 9.2.0。交互使用真实 Qt 控件及 Matplotlib 事件，框选和三维画面使用原生 VTK。
Windows EXE 未在此环境构建或实机验收，使用者需重新构建。

详细输出分析覆盖 Gaussian 和 ORCA 的常见打印格式；轨道、系数或收敛表未打印时不能恢复缺失数据。
其他 ASE 轨迹使用已有能量/力信息，不声称已经完成各程序的全部结果解析。
显示同步要求原子序列一致，不对删原子、真实扩胞等改变原子集合后的帧猜测身份映射。
曲线和轨道值属于源输出，结构编辑不会产生新计算结果；未加入等值面或结构搭建功能。
