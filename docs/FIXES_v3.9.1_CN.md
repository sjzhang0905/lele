# LELE 3.9.1 更新说明

- 原子选中标记改为连续闭合绿色实线环，保留现有粗细及跟随视角的行为。
- 导出 POSCAR Direct 或 Cartesian 时，默认文件名和最终保存文件名均以 `POSCAR` 开头。例如输入 `sample` 保存为 `POSCARsample`；输入 `POSCARsample` 不重复添加前缀；`poscar1` 规范为 `POSCAR1`。目录和其余文件名内容保留，文件名前缀改变后若目标已存在会再次确认覆盖。
- 选择保存位置后询问 **Merge same elements?**：Yes 将同种元素集中成一个分组；No 保留当前原子顺序及原有重复元素分组；Cancel 取消本次导出。
- 合并按元素首次出现顺序排列，每种元素内保留原顺序。例如 `O C O H C` 导出为 `O O C C H`，元素头为 `O C H`。仅调整导出副本，原子坐标及固定约束同步重排；画布、当前选区和保存的片段保持原样。
- 混合占据仍先询问是否使用最大占据元素，随后再按实际导出的元素合并。CIF、XYZ、GJF 等其他格式保持原行为。
