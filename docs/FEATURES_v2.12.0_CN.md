# LELE v2.12.0：分数占据、原子编号与真空层

日期：2026-11-02。包含此前 v2.11.0 的周期旋转和 v2.10.1 的 A1–A3 修复。

## 1. CIF 分数占据

读取 CIF 的 `_atom_site_occupancy` 并保留到对称性展开后的每个位点。相同位点的混占元素按占据率显示为不同元素颜色的球面扇区；未占据部分显示为浅灰半透明扇区。例如 Fe 0.6 / Ni 0.4 为两种颜色，O 0.5 为半球氧色和半球浅灰。颜色沿用当前元素配色，原子自定义颜色仍优先。

![分数占据和绿色虚线选中轮廓，原生 VTK 渲染](qa_v2.12.0/partial_selection_native.png)

图例包含混占中的少数组分。在原子列表悬停或右击原子，可查看具体占据率；底部 composition 显示按占据率加权的组成。Atoms 数为可视化位点数；分数占据不指定唯一的微观整数构型，因此电子奇偶性显示 `unknown`，不按主元素虚构 `even/odd`。成键仍以位点代表元素估计，不能据此把平均结构当作唯一有序原子构型。

占据信息跟随 `.lele` 项目、Boundary、扩胞、删除、重编号及 LELE 内部复制粘贴保存。CIF 导出保留混占与占据率。XYZ、POSCAR、GJF 等不支持这些位点概率的输出不再静默丢弃占据率：需先构建明确的有序构型，或保存为 CIF。外部纯 XYZ 剪贴板不包含占据率，LELE 原生剪贴板元数据包含。

占据率定义依据：[IUCr CIF `_atom_site_occupancy`](https://www.iucr.org/__data/iucr/cifdic_html/1/cif_core.dic/Iatom_site_occupancy.html)。读取沿用 ASE 的 CIF 对称性展开及 `spacegroup_kinds` 映射，未执行随机整数化。

## 2. 右击原子设置 index

右击画布中的原子打开 **Atom index** 窗口。`New index (1-based)` 使用坐标表中的全局编号，从 1 到 N。设置后，该原子移动到指定行，中间的编号顺移，保证编号唯一。

先选中两个原子，再右击其中任意一个，窗口会出现 **Swap indices #… ↔ #…** 按钮，可直接交换这两个原子的编号。

这是实际原子顺序变更；坐标不作空间移动，元素、占据率、颜色/透明度和键的归属跟随各自原子，周期键/氢键的平移方向也同步重映射。操作只作用于当前结构帧，原有标量能量和收敛标记保留，POSCAR 导出保留新顺序。Ctrl+Z 撤销完整变更。振动参考或轨迹显示对齐状态下只允许查看，沿用原有几何编辑限制。

右击空白位置仍清空选区，右键拖动仍为视图 roll。

## 3. 修改 slab 真空层

入口：**Edit → Modify slab vacuum…**，或 Edit 面板同名按钮。窗口自动比较 a、b、c 三个方向的周期空隙，也可手动选择。

这里的真空厚度定义为：沿另外两个晶胞矢量所张平面的法向，从 slab 最上方原子核所在平面到相邻周期副本最下方原子核平面的距离。窗口同时显示 slab 厚度、上下表面投影、晶胞法向高度和当前真空间距。计算包含占据率大于零的吸附原子，未扣除原子半径。

填写目标 **Vacuum spacing** 后，只修改所选晶胞矢量在表面法向上的分量。原子笛卡尔坐标保持逐项不变，另两条晶胞矢量、所选矢量的面内分量、元素、编号和周期标记保持不变。支持斜晶胞及整体旋转后的 slab；不把 `|c|` 直接当作真空方向高度。

如果 slab 的原子代表坐标分散到晶胞两端，修改晶胞会改变其跨边界内部距离；在保持每个原子坐标不动的要求下无法完成时，窗口明确提示并禁用应用，不会偷偷平移原子。可先明确选择连续的周期代表坐标，再调整真空。附带固定体数据网格时需先单独打开结构进行晶胞修改。

改变真空后，源能量、收敛标记及相关力数据被清除，因为原计算对应不同的周期晶胞；其他输入元信息保留。Ctrl+Z 恢复原晶胞、能量和坐标。对于不规则孔道、多个分离片层或复杂体相，“最大空隙”只是几何候选，请结合显示的表面和厚度选择方向。

## 4. 底部摘要对齐

`Atoms | Composition / Formula | electrons…` 所在行左侧动态对齐到 **Coordinates / Input / Results** 标签页的左边缘，不再按固定宽度从窗口左侧偏移。短接触按钮、可编辑测量值及状态信息保留。

## 5. 绿色粗虚线选中轮廓

选中效果改为面向镜头的绿色粗虚线外环，位于原子轮廓之外。没有覆盖球体的网格，不改变原始元素色，也不覆盖中心 label / index。真实断开的线段保证 VTK 后端可见虚线，不依赖驱动对线型的可选支持；Boundary 的各个可见副本也沿用该轮廓。

验证结果见 [v2.12.0 复验记录](VALIDATION_v2.12.0.md)。
