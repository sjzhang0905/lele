# v1.7.1：跨晶胞片段选择与反选修复

日期：2026-10-28

## 原因

之前 Ctrl+G 在画布里添加相邻晶胞的显示副本，底层 Frame 仍只有原晶胞的原子。
Coordinates 从 Frame 读取坐标，Ctrl+I 也只遍历这些原子，因此坐标表没有新增行，
反选无法包含画布中新显示的副本。

## 现在的行为

- Ctrl+G 先寻找相连的有限周期片段；需要相邻晶胞时，建立足以容纳片段的真实超胞。
- 每个新增原子都有独立编号，Coordinates、Atoms、底部原子总数和画布同步更新。
- 只选择完整片段所对应的具体原子副本；其他副本保持未选中。
- Ctrl+I 对当前超胞内全部原子取补集，能接着删除、编辑或复制选中的原子。
- 对已经完整显示的同一片段再次 Ctrl+G，不会继续扩胞。
- 自动扩胞是当前工作结构的修改；Ctrl+Z 恢复原原子、晶胞、选区、能量及体数据。
  输入文件不会自动覆盖，其他轨迹帧保持原状；导出时使用当前结构。
- 位于原晶胞内部的片段仍只改变选择，不修改结构，也不添加撤销记录。

自动扩胞复用手动扩胞的处理：支持斜晶胞及部分周期边界，复制逐原子显示设置，
映射手动成键/断键；旧能量清空、旧体数据解除关联、已知净电荷按晶胞数倍增，
不推断新多重度。负方向扩胞会把新超胞原点平移到零，各原子的相对位置保持正确。
无限周期网络仍不能作为有限分子展开，保留原有提示。

例如原晶胞有 4 个原子，其中一个水分子跨 a 方向边界。自动 2×1×1 扩胞后，
坐标表显示 8 行，选中完整水分子的 3 个实际副本；Ctrl+I 选中其余 5 个原子，
再次 Ctrl+I 恢复原来的 3 个原子。
