# LELE 0.9.4 验证记录

日期：2026-10-26

## 本次修改

- 用 File、Edit、View、Analysis、Help 五个菜单取代顶部宽工具栏。
  原有打开、导出、截图、撤销、反选、删除、片段选择和成键快捷键继续可用。
- View 菜单中的 X、Y、Z 分别从对应的坐标正轴朝结构观察；仅改变相机。
  正交/透视投影归入 Projection 子菜单，其勾选状态与实际相机一致。
- 底部先显示当前帧的原子总数，再显示 Cell composition 或 Formula，以及短距离检查。
  移除电子数显示及原来仅用于电子数诊断的净电荷输入。
- 选中原子不会自动计算或显示最佳平面。选择至少三个原子后，通过左侧 Edit 页
  或 Edit 菜单中的 Fit selected plane 生成平面。
- 已生成的平面在选区、拟合原子坐标、晶胞、周期镜像选项或活动帧改变后失效。
  隐藏/显示已拟合平面不会重新拟合；显式对齐到 XY 后更新相应平面，支持撤销。
- Edit 页说明文字自动换行，使平面按钮和方程在默认侧栏宽度内完整显示。

## 检查结果

- 完整回归测试：**129 项测试通过，64 个子测试通过**，无失败、无跳过。
- 通过调用次数检查确认：选择原子、刷新场景及隐藏/显示平面都不会隐式启动拟合；
  点击按钮或菜单命令时才拟合。共线选区在点击拟合后显示错误，坐标不变。
- 检查选区、坐标、周期镜像选项和活动帧改变后的平面失效行为。
- 检查平面对齐及撤销时的原子坐标、晶胞、网格几何和选区恢复。
- 逐一检查 X/Y/Z 菜单实际产生的观察方向，以及投影切换时的方向和坐标保持。
- 检查原子统计在删除/撤销后随完整帧更新，不随选中原子数量改变。
- 已检查真实 Qt 菜单、侧栏和统计行的布局截图。默认侧栏中 Edit 内容宽度与
  可视区宽度均为 340 像素，无横向滚动；拟合方程和 RMS 文字完整显示。
- 欢迎页、0.8 秒逐帧瞬移动画、文件打开和相关快捷键的已有回归测试通过。

执行命令：

```bash
QT_QPA_PLATFORM=offscreen VTK_DEFAULT_OPENGL_WINDOW=vtkEGLRenderWindow python -m pytest tests -q
```

Linux、Python 3.12.14、PySide6 6.12.0、VTK 9.7.1、ASE 3.29.0。
Qt 使用 offscreen 平台；独立 VTK 渲染使用 EGL。
本次交付为源码包，未构建 Windows EXE，未在原生 Windows 下验证嵌入式 OpenGL，
