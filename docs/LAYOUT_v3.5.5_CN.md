# LELE 3.5.5：底部输入框宽度修正

3.5.3 已缩短下拉选择框，但带上下箭头的数值输入框仍会撑满表单行，本版补齐这部分。

- Axes 长度、Labels 字号、Field 透明度/线宽/网格间距、WAVECAR Band、Boundary 起止值等普通数值框统一 90 个逻辑像素。
- 正负等值面数值框采用 140 个逻辑像素，为高精度数值和科学计数输入保留空间。不会改变数值精度、上下限或键盘输入行为。
- 底部下拉框继续为 90；输入控件靠左，窗口或底部面板加宽后不再拉长。
- 正等值面输入与 Apply 按钮相邻；Boundary 六个数值框按行列集中靠左，不再横向均匀分散。
- 水平滑杆仍最长 265，允许在窄行中缩短。

在 Qt 的 Windows/Fusion 样式下检查默认和加宽面板，所有相关输入保持紧凑，包括暂时隐藏的 WAVECAR 区域。检查采用 Linux Qt 无窗口环境及截图目检，并非 Windows 原生桌面实机验收。极窄面板仍可通过滚动查看完整 Field 表单。

保留 3.5.4 的 Boundary 等值面修复以及此前全部启动、大文件读取和界面改动。

完整回归：1489 项通过，12 项跳过，78 项子测试通过。发行 wheel 的 131 个 Python 模块与源码逐字节一致。
