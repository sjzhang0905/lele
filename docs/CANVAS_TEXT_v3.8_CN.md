# 画布文字

在 `Edit → Canvas text → Add text…` 输入文字、字号（以 Å 表示）、颜色，确认后在画布上点击放置。支持多行文字；如需中文等字形，可选择包含对应字形的 TTF/OTF 字体文件。

文字是三维场景中的独立对象，创建时正对当前镜头。以后旋转整个结构时，文字也随场景旋转，不会始终正对镜头。

- 单击文字选择；绿色矩形表示当前选中的文字。
- 按住 Alt 并拖动鼠标中键，移动选中的文字。
- 按住 Alt 并拖动鼠标左键，三维旋转文字；Alt 加右键拖动则沿视线方向旋转。
- 右击文字可以修改内容、字号、颜色或删除。Delete 删除选中文字，Ctrl+Z 撤销添加、删除、内容修改和一次拖动操作。
- `Choose text…` 可以找到暂时旋转到侧面或画布外的文字并修改。
- 添加文字后、点击放置前，Esc 取消放置。

每个已打开的文件有各自的文字，切换文件不会混用。文字保存在 `.lele` 项目中，并出现在 PNG/GIF 场景导出中；XYZ、GJF、CIF 等原子结构格式不包含这些显示注释。字体文件只保存路径，迁移到另一台电脑时应保证所选字体可用，否则回退到默认字体。
