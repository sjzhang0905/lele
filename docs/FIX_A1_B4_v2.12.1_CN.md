# LELE v2.12.1：七项独立验收问题修复

2026-11-02。修复对象为 v2.12.0 的 A1–A3、B1–B4，保留周期结构的矩阵旋转及绿色粗虚线选中轮廓。入口仍见 [v2.12.0 使用说明](FEATURES_v2.12.0_CN.md)。

| 编号 | 修复后的行为 |
| --- | --- |
| A1 等价晶位混占 | 根据原始 CIF 组分及其对称轨道合并占据率。相差整数晶格平移或属于同一反演轨道的 Co 0.6、Ni 0.4，展开后的每个对应晶位均保留两组分。特殊位置和重复书写的同组分不会重复计数；同组分的等价代表占据率冲突时报告错误。CIF 导出重读保留组分。 |
| A2 POSCAR 固定标记、顺序 | 保存逐原子、逐方向固定标记。原样导出、修改真空及重编号后，Direct / Cartesian POSCAR 均保留 `F F F`、`T F T` 等标记。导出不再自动按元素排序，保留实际原子行及连续元素块，包括原输入中的重复元素块。重编号时固定标记随原子移动，项目保存也保留。 |
| A3 跨帧原子身份 | 跨帧几何监视、外观同步、显示对齐、振动选区、配位轨迹及偶极匹配共用已知原子身份映射。同种原子交换编号后，不再仅凭元素和当前行号匹配。新增监视项保存建立时的参考身份，后续重编号和项目重开仍跟随原子；映射无效时留空或跳过。 |
| B1 确认原真空值 | 完全不改变结构及结果，不清空能量、收敛标记或增加撤销记录。弹窗未编辑时使用原始精度，避免六位小数显示引入隐含晶胞变更。实际修改晶胞时继续清除原计算结果。 |
| B2 小真空回读 | 第一次成功修改后保留已确认外表面的相对投影。外部真空小于内部层间距时，再次自动或手动选择该方向仍读回目标值，可以继续调整。证据保存在 `.lele` 项目中，兼容几何仍匹配的 v2.12.0 修改记录。 |
| B3 底部自动对齐 | 窗口缩放及状态栏布局变化自动触发延迟对齐；先更新待处理布局再计算偏移，避免重复使用旧坐标累积修正。正常事件循环下无需手动调用内部函数。 |
| B4 Chemcraft CIF | 未写空间群名称/编号、但明确给出恒等操作 `x,y,z` 的 CIF 可以直接导入，包括无 occupancy 列的文件。缺少名称/编号且包含非恒等操作时明确报错，不自行猜测空间群。 |

实际 POSCAR1 共 100 个原子、96 个完全固定；三个导出路径均保留固定标记，原样和单改真空保留 `Co Se S Li` 元素块顺序。原始 22.cif 可直接读出 434 个原子。

真空初次识别仍以最大周期空隙作为候选；多片层、孔道及首次打开就存在很小外部间距的结构需要结合显示的表面信息判断。确认表面身份的记录依赖 `.lele` 元数据，导出为普通 POSCAR/CIF 后这些格式不会携带该应用记录；重新导入会重新识别。若后续坐标修改破坏了已记录的法向投影，程序也会重新识别。仍不自动平移边界两端的原子代表坐标。

原子映射依赖轨迹原始行身份及 LELE 中的已知重排；没有对无对应关系的独立文件执行空间猜配。旧项目缺少新监视项的参考身份字段时仍可读取，但不能凭空恢复过去未记录的参考顺序。

复跑命令、日志和图形检查见 [验证记录](VALIDATION_v2.12.1.md)。
