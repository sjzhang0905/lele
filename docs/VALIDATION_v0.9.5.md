# LELE 0.9.5 验证记录

日期：2026-10-26

## 本次修改

1. 动画使用原始帧图中的前四帧，按“站立→左腿→站立→右腿”重复。
   保留每帧 800 ms、帧间位置不动的行为。每次横穿画布使用 32 帧、25.6 秒，
   包含八个完整步态周期，避免步态循环及画布回到左侧时出现多余站立帧。
2. 底部恢复 Electron parity，只显示 Odd/Even 及净电荷说明，不显示电子总数。
   Edit 页恢复净电荷输入；切换活动帧时同步该帧的电荷，不把当前输入覆盖到另一帧。
3. 使用第一帧站立鹦鹉生成透明 ICO，朝向与欢迎页一致，包含 16、24、32、48、64、
   128、256 像素尺寸。本地 Windows 打包和 GitHub Actions 均嵌入该图标，窗口也使用同一图标。

## 验证

- 完整测试：**130 项测试通过，64 个子测试通过**，无失败、无跳过。
- 动画回归跨越两个完整横穿周期，确认姿态始终按 0、1、2、3 循环，
  无额外站立帧；原有 800 ms 定时、帧间保持不动和隐藏暂停检查继续通过。
- 原子/净电荷奇偶性检查通过；真实 Qt 控件中修改电荷、切换活动帧、删除/撤销
  后的统计更新检查通过。显示内容没有电子总数。
- 图标已人工查看。Qt 可读取 ICO 并生成非空窗口图标；ICO 内包含全部七种尺寸。
- 已实际构建 Python wheel 并核对其中包含 ICO 和 PNG 图标及原始帧图，
  无需增加程序运行依赖。检查本地与 GitHub Windows 打包命令均包含正确图标路径。
- `examples/welcome_preview.gif` 已按动画控件重新导出：32 帧，每帧 800 ms，
  循环总长 25.6 秒；预览仅包含动画区域。

```bash
QT_QPA_PLATFORM=offscreen VTK_DEFAULT_OPENGL_WINDOW=vtkEGLRenderWindow python -m pytest tests -q
```
