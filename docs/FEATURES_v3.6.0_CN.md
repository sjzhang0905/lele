# LELE 3.6.0：Selection、Fragment 与应用新坐标

日期：2026-11-10

## 底部三栏

从左到右为：

1. 原有 Axes / Labels / Field / Boundary。
2. Coordinates / Input-output text / Results-info。
3. 新增 Selection / Fragment。

三栏之间可拖动调整宽度。操作按钮保持内容所需宽度；明细表可以手动调整列宽，列较多时使用横向滚动条。

## Selection

显示当前选中的源原子，按当前原子序号排列；序号从 1 开始，连续三个及以上编号压缩为区间，例如 `1, 2, 5-8, 24`。Boundary 的显示副本对应同一个源原子，不额外产生真实编号。

| 字段 | 含义 |
| --- | --- |
| Index / Element | 当前序号、元素 |
| Occ. % | 该位置上该元素的占据百分比；混合占据按元素分行，保持相同源序号 |
| Cartesian X/Y/Z | 笛卡尔坐标，单位 Å |
| Direct X/Y/Z | 周期性结构的分数坐标；不强行包回 0–1，和 Cartesian 保持一致 |
| Fixed X/Y/Z | 有可靠固定信息时显示；T=固定，F=未固定，—=未知 |

固定方向可能属于 Cartesian 或 Direct，表下方及表头提示会说明。这里的 T/F 表示“是否固定”，不是照抄 POSCAR 的移动许可标记。没有固定信息时不假定所有原子都自由。

坐标编辑、原子重排、删除、扩胞、换帧、切换文件和撤销后，Selection 与 Coordinates 同步。表格按需格式化可见单元，未选择原子时不扫描整个结构的固定标记；普通刷新保留列宽和横向滚动位置。

各程序已核对的语法、输出信息缺失的处理以及复杂情况见 [固定原子信息读取范围](CONSTRAINTS_v3.6.0_CN.md)。

## Fragment

选中原子后点击 **Save selection**，依次生成 `fragment1`、`fragment2` 等。名称序号递增，删除旧片段后不复用其序号。

- 点击列表中的片段，快速选择其成员。
- **Delete** 删除保存的片段定义，不删除原子。
- **Move to first / Move to last** 把片段成员作为一组移至原子序列开头或末尾。片段内部及其余原子的相对顺序均保持不变。
- 保存、删除、选择和重排可以撤销；成员编号、Selection 和 Coordinates 立即更新。

例如序列 `1,2,3,4,5,6`，保存成员 `2,4,5` 后移至开头，实际顺序变为原来的 `2,4,5,1,3,6`，显示编号则重新连续编排。元素、占据率、颜色、固定信息、普通键、周期键和氢键随原子身份移动，几何位置不变。

片段定义属于当前结构帧，随 `.lele` 项目保存；不会自动套用到其他文件或其他轨迹帧。删除原子时片段移除对应成员，变空的片段自动移除。扩胞时片段包含相应副本；从别的文件粘贴原子不会把其片段名称混入当前文件。

## File → Apply new coordinates

1. 载入作为模板的计算输入文件，然后切换到希望应用的结构。
2. 在 **File → Apply new coordinates…** 中选择一个已加载的输入。
3. 查看差异预览。确认后点击 **Apply**，更新该输入文件，并同步刷新其已加载副本。

预览不会写文件。应用时自动保存原始文件备份，如 `calc.inp.lele.bak`；已有备份不会被覆盖，后续依次使用 `.lele.bak.1` 等。若文件在预览后被其他程序修改，会停止应用并要求重新预览。取消不改文件。

替换采用原文片段修改，保留与结构无关的参数、设置、注释、编码和换行。保存前重新解析生成的输入，比较元素顺序、Cartesian 坐标和周期晶胞，验证失败则不写入。该功能不调用计算程序。

### 晶胞与目标格式

- 周期性结构 → 周期性输入：使用当前实际晶胞。
- 孤立结构 → 周期性输入：使用 **30 × 30 × 30 Å** 立方晶胞。
- 周期性结构 → 孤立输入：只应用原子坐标，不添加源晶胞信息。
- 保持目标原有的周期性计算设置。例如 Gaussian 原有三条 `Tv` 视为周期模板；没有 `Tv` 的分子模板不会自动变为周期计算。
- CP2K `PERIODIC NONE` 仍需要积分计算盒，因此保留目标原有 CELL；不会删除它或擅自修改 Poisson 等计算设置。

这里使用真实结构帧，不把 Boundary 显示副本、振动动画位移或轨迹显示对齐当作新原子坐标。对齐显示/振动模式下应先回到普通结构帧。

### 输入范围与保护

| 程序 | 自动替换范围 |
| --- | --- |
| Gaussian | 单个 Cartesian 分子段；保留 freeze 列及后续参数；已有三条 Tv 时更新晶胞 |
| ORCA | `* xyz` 与 `%coords` 的内嵌 Cartesian 坐标，包含 Bohr/Å 单位 |
| NWChem | 单个分子 `geometry` Cartesian 段、明确单位与原子标签 |
| CP2K | 单个 FORCE_EVAL/SUBSYS 的内嵌 COORD/CELL，包括常见 restart、KIND 别名、scaled/Bohr/Å |
| Quantum ESPRESSO | `ibrav=0`、显式 CELL_PARAMETERS 与 ATOMIC_POSITIONS；保留 if_pos |
| SIESTA | 内嵌原子坐标与晶胞块；支持明确的 Cartesian/分数坐标单位 |
| VASP POSCAR | 缩放因子、Direct/Cartesian、Selective Dynamics；保留已确认的附加记录 |

简单分子模板可接收不同原子数量和顺序。纯坐标的 CP2K/QE/SIESTA 模板在没有原子专属记录、各元素已有唯一 KIND/species 定义时，也允许改变数量，并同步结构计数。完整条件见 [周期性输入替换范围](COORDINATE_TEMPLATES_PERIODIC_v3.6.0.md)。原子专属设置、固定列表、局域基组、磁矩列表、连接关系、速度等与编号有关时，不能把它们静默套到另一个原子；无法验证身份对应关系的数量或顺序变化会被拒绝。同元素原子重排也检查这一点。

POSCAR 物种块顺序关联外部 POTCAR，不能只改 POSCAR 表头来完成跨物种重排。混合/部分占据结构也不会自动丢弃占据率；需要先明确导出或处理为确定占据结构。

暂不自动处理未验证的多任务/多结构、Z-matrix、Gaussian ONIOM/Link1/QST、ORCA 外部坐标/复杂片段、CP2K include/多 FORCE_EVAL、NWChem SYSTEM 周期块，以及复杂 MD 续算状态。这些情况会给出具体原因并提示提供样本，不会自动降级为“重新导出一个输入”而丢失原设置。
