Linux、Python 3.12.14、PySide6 6.12.0、VTK 9.7.2（真实 EGL 离屏渲染）。

运行 `QT_QPA_PLATFORM=offscreen VTK_DEFAULT_OPENGL_WINDOW=vtkEGLRenderWindow python -m pytest tests -q --timeout=45 --tb=short`；超时保护来自仅测试使用的 pytest-timeout。

**1,878 passed、16 skipped、78 subtests passed**；140 条警告主要为 VTK 9.7 API 弃用提示及既有依赖警告。详细日志与 JUnit XML：`verification/v3.8.0/full_suite_final.log`、`full_suite_final.xml`。

## 本次专项验证

- SVG 保留矢量路径及可编辑文本；栅格图像尺寸、平滑、失败时原文件保护、图像导出后画布状态恢复。
- PNG/GIF、图例、NEB 毛毛虫图的真实离屏渲染；文字包含在导出结果中，并在高分辨率捕获时提高字体栅格精度。
- XRD：简单立方、BCC 消光、金刚石 Si 峰位、多重性、混合占据、斜晶胞及 CSV。Si 前三峰约 28.44°、47.30°、56.12°（Cu Kα1）。
- STM：VASP 原始场的体积归一化、共线自旋通道重建、恒高、恒流首个外侧交点、无交点、跨周期 slab、强斜晶胞采样、重复和输出。实际提供的 PARCHG 文件为 38 原子及 168×168×480 网格；两类地图均成功生成，数值及预览见 `verification/v3.8.0/stm_*`。
- 文字：真实三维旋转与平移、屏幕拾取、删除与撤销、跨文件隔离、项目保存恢复、坐标替换后保留。
- 外观：默认尺寸/色值/不透明度、四灯独立切换及项目往返、自定义颜色不重复混白、加粗绿色虚圈。
- 片段平移：缓存图形预览、坐标及键关系保持、一次撤销、释放/中途刷新清理；遇到需要变形的跨组连接或多面体等场景保留完整重绘。
- 滚轮：下拉框和数值框获得焦点后仍不随滚轮改值；展开列表滚动、面板滚动及画布手势保留。
- 格式：GBW 明确拒绝，不调用外部转换器或读取同名输出；GJF/XYZ/CIF 自动后缀后的真实文件可读回。
- Field 左侧窄栏检查：295 px 侧栏不产生水平滚动；数值输入和 Apply 完整可见。最终宽度调整后再运行三项界面/键盘回归，详见 `final_sidebar_checks.log`。

## 测试维护

旧布局/尺寸断言随用户指定的新默认值更新。NMR 保存测试显式处理新增的栅格分辨率对话框；PNG/GIF 映射颜色测试统一相机，避免比较不同半球。

完整测试中，较早窗口的 `deleteLater()` 清理会干扰后续 ORCA 定时器测量。现在在该计时测试开始前显式处理 Qt DeferredDelete，保留原来的 `ticks >= 3`、主线程挂接、2,403 帧/偶极及帧导航断言。生产解析与工作线程代码没有为此更改。

## 使用范围

XRD 是理论粉末谱正向模拟，不做实验谱的 Rietveld 精修。STM 的恒流设定值为等密度值，不能从单个 PARCHG 文件校准为绝对 nA，也不从文件名推断偏压。三维场景使用可设分辨率和平滑的 PNG/GIF，二维绘图优先使用 SVG。
