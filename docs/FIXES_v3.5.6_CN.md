# LELE 3.5.6：CP2K 与紧凑控件修复

日期：2026-11-10

## CP2K restart

- 修复 CP2K 自动写出的反斜杠续行导致读取失败的问题，保留原始源行号。
- 支持 `.restart`、`.restart.bak-*` 及内容相同的重命名文件；文件选择器增加 CP2K 筛选项。
- 正确读取晶胞、分数坐标、KIND 别名（如 Ni_dn、Mn_up），以及重启步数和 MD 时间。
- 正确识别 restart 展开写出的 PBE 等泛函；`NO_SHORTCUT` 不再作为计算方法显示。
- restart 仍是当前结构与设置快照，不将速度、恒温器状态或 `ECONS_START_VAL` 当作完整轨迹或电子总能量。

## CP2K 输出 Summary

底部 Results / info 和计算概览补充文件实际打印的数据：

- 版本、项目、任务、原子数、Quickstep 方法、自旋处理。
- 各 KIND 的基组、赝势、DFT+U 方法及 Ueff；网格与截断参数保留原输出单位。
- SCF 请求初猜、内外层收敛设置、最后 SCF 迭代和收敛状态。
- MD 系综、计划步数、时间步长、目标温度、恒温器及最后打印状态。
- 区分 MD 步号、电子能量评估和温度等统计；支持步号位于能量前或后的打印顺序。

LOW 级别输出未打印的 XC、具体基组、电荷、多重度或坐标仍保持缺失，不从文件名或旁边的 restart 猜测。多个计算拼接时，各段元数据独立。

## Atoms 与颜色控件

- 每一列均可拖动表头边界调整宽度；刷新、编辑和切换文件不会重置手动列宽。
- 默认 Atom / show 列加宽；`Occupancy %` 改为 `Occ. %` 并缩窄。默认窄侧栏下可同时显示 `Cl100 · #100` 和 `100%`。
- 界面中的 `colour` / `Colour` 统一为 `color` / `Color`。
- Atoms、元素、背景、标签、等值面层、晶面和多面体边颜色均采用方形色块，不在控件上显示十六进制字符串。
- 颜色值与按钮文字分开保存；颜色选择、工程保存和恢复继续保留真实色值。

## 底部按钮

字体选择、Boundary Apply / Reset 以及 Field 等底部操作按钮保持自然宽度并靠左排列；拖宽面板不会再让按钮铺满整行。保留已有输入框、下拉框和滑杆宽度限制。
