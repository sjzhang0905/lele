# LELE 3.5.4：Boundary 等值面跟随扩展

## 修复

普通 CUBE 文件会载入网格定义的晶胞，但没有声明其数值可以周期插值。旧版只复制标记为周期数据的等值面，因此 Boundary 扩展了原子，CUBE 等值面却留在原处。

新版将显示复制与数值周期性分开：当网格跨度与晶胞一致时，Boundary 按相同晶格平移复制已有等值面。正/负等值面、多个显示层、Surface/Wireframe/Points 表现方式和透明度随副本保持。有限 CUBE 场仍使用原有网格，不补造周期接缝，不修改密度数值，也不将文件改标为周期场。

密度/电势映射的副本使用各自对应的原始坐标取色，负方向扩胞时也不会因超出原颜色网格而变灰或消失。已有周期 CHGCAR 保留原来的周期接缝与边界裁切处理。

## 使用

在 Boundary 中设置范围后点击 Apply。例如 a、b 为 0–2，c 为 0–1，会显示 2×2×1 个晶胞及对应等值面。Reset 会恢复原有单份显示。

若外加网格跨度与结构晶胞不同，程序保留该网格原有显示，并在 Field 说明处提示不能按晶胞复制；不会强行缩放或拉伸原始数据。

## 验证

回归包含真实 CUBE 读取到 Boundary 面板 Apply/Reset 的流程，以及正负等值面、多层、负方向范围、斜晶胞、颜色映射、源数据不变和非周期分子不复制。另用此前提供的 CHGCAR 样例验证 2×2×1 扩展。测试使用真实 VTK 几何和 Qt 无窗口测试环境，没有进行 Windows 原生桌面实机验证。

新增 8 项专项检查全部通过；同组检查在 3.5.3 上有 5 项失败、3 项通过，确认新增检查能识别原缺陷。

完整回归：1489 项通过，12 项跳过，78 项子测试通过。发行 wheel 的 131 个 Python 模块与源码逐字节一致。
