# LELE 3.9.0 功能说明

## 电荷密度加减运算

从左侧 **Field → Add / subtract fields…** 打开场数据加减运算窗口。选择已加载的数据场，或者从文件加入新的数据源；每一项明确选择数据通道及 `+` / `−` 运算，可组合为 `A+B`、`A−B`、`A−B−C` 等。

运算结果成为当前文档的一个新数据场，原始网格保持不变。结果可继续用于等值面、二维切面和已有 CUBE 导出，并随 `.leleproject` 保存实际网格及来源公式。重新打开项目不需要重新找到参与运算的原始文件。

已指定固定数据源的自定义等值面层会保留其原设置；要让这些层显示新结果，请在 Surface layers 中将数据源改为新场。基本正／负等值面和切面使用当前选中的场。

- 各项必须具有一致的网格尺寸、原点、网格方向和周期属性；不自动平移、旋转、插值或拟合结构。
- 差分电荷允许不同原子组成的参考片段，但它们必须在同一个空间网格上计算。例如吸附体系总密度减去相同晶胞与网格中的基底密度及吸附物密度。
- 已知兼容单位进行换算；密度、势能、轨道振幅不能混加。普通 CUBE 未必说明标量物理单位，未知单位需要用户明确指定，不根据文件名猜测。
- 每个操作数都明确指定通道。对于自旋极化结果，需自行选择总密度、磁化密度等对应通道，不自动把不同通道当作等价物。
- 多项运算在分块双精度累加后保存为 LELE 使用的 float32 网格。大数据处理显示进度并支持取消；失败或取消不加入半成品。

## 按元素选择原子

底部右侧的三个标签依次为 **Current selection**、**Fragment**、**Atoms selection**。

**Atoms selection** 按结构中元素出现的顺序列出元素及数量，每种元素右侧一个输入框。输入 `1,2-10,24` 后按 Enter，选择该元素内部编号为 1、2–10、24 的原子。也支持中文逗号。

编号与左侧 Atoms 标签中的 `O1`、`O2` 等一致，**不是整个结构的全局原子编号**。例如文件顺序为 `C、O、H、O`，在 O 行填写 `2` 会选中全局第 4 个原子。

所有非空元素行合并成一个选区；清空所有行后按 Enter 清空选区。错误格式或超出元素数量会在对应行提示，原选区不变。混合占据中的元素各自列出，选择不同组分对应的同一位点时不重复选择。普通选择刷新保留输入；切换结构、调整原子顺序或更换元素后清除旧表达式，避免旧编号误选。

输入元素选择表达式时自动暂停轨迹播放，避免输入过程中跳到另一帧。

## 画布片段快捷键

先单击画布使其获得键盘焦点，数字使用 **1–9**。

| 快捷键 | 行为 |
|---|---|
| `Ctrl+数字` | 把当前选区保存为对应 `fragment1` 至 `fragment9`；同名已存在时覆盖 |
| `数字` | 选择该片段中的全部原子，替换当前选区 |
| `Shift+数字` | 把当前选中的原子追加到对应片段，自动去重；片段不存在时创建 |

空选区不会覆盖或清空已有片段。未保存的编号不会改变选区；`0` 没有片段快捷键。长按不重复写入撤销历史，输入框内的数字及组合键保持输入框原有行为。

快捷键使用 Fragment 标签中已有的片段记录；可继续点击选择、删除或调整原子顺序。片段属于当前文件的当前帧，支持现有 Ctrl+Z 撤销和项目保存，删除原子或重排后成员编号随原子身份更新。
