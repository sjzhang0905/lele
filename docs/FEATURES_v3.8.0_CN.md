# LELE 3.8.0 功能说明

## 导出与界面

- 谱图、曲线、切片、STM、XRD 等 Matplotlib 图统一优先保存 SVG，也可保存 PDF。PNG/JPEG/TIFF 可以设置输出像素和平滑；平滑只影响图像渲染，不修改科学数据。
- 主画布、原子图例、NEB 毛毛虫图使用 PNG，均可设置分辨率和平滑。GIF 保留分辨率、帧率和平滑选项，包含画布文字。
- Field（等值面）标签从底部移到左侧。Axes、Labels、Boundary 保持在底部。
- 全局禁止滚轮直接改变下拉框及数值输入框，即使已获得焦点；键盘、手动输入和上下箭头仍可用。悬停这些控件时，滚轮滚动所在面板；展开的下拉列表仍可滚动浏览。
- GBW 支持已取消，不再自动运行 ORCA 转换器或读取同名输出作替代。ORCA 输出、Molden 和 CUBE 保持支持。
- 导出 GJF/XYZ/CIF 时，缺失或不匹配的后缀自动追加所选格式后缀。例如导出 XYZ 时 `model.out` 保存为 `model.out.xyz`；POSCAR 命名不变。

## STM

打开 `PARCHG*` 文件后，选择 **Analysis → STM from VASP PARCHG…**。

支持恒高密度图与恒流等密度高度图；可选上/下表面、晶格法向、密度通道、平面重复、色图与高斯平滑。恒流设定值是电子密度（e/Å³），不是可直接校准的 nA。文件的能量窗口由原 VASP 计算决定，不从文件名的 `+0.3` 自动假定偏压。

实现参考 p4vasp 的恒高/恒流思想，独立实现采样与交点算法。斜晶胞按真实表面法向采样，未找到交点的像素保留空缺。详见 [STM 说明](STM_v3.8.0_CN.md)。

提供的 `PARCHG+0.3` 为 38 原子、168×168×480 网格。已实际读取并生成两类 STM 图；验证结果及预览在 `verification/v3.8.0/stm_*`。

## XRD

周期结构选择 **Analysis → Simulate powder XRD…**。由当前晶胞与原子结构计算粉末衍射谱，支持混合占据、波长、2θ 范围、峰宽、Gaussian/Lorentzian 峰形、LP 与各向同性 B 因子。可导出谱图、曲线 CSV 和含 hkl、d 间距与强度的反射表。

这是类似 VESTA 的理论粉末谱模拟，不是对实验谱进行 Rietveld 结构精修。单一波长、中性原子散射因子；真空层按所给周期晶胞参与计算。详见 [XRD 说明](XRD_v3.8.0_CN.md)。

## 默认外观与灯光

| 设置 | 新默认值 |
|---|---|
| Ball and stick 原子尺寸 | 50 → 47 |
| Bond thickness | 7 → 6 |
| Default 原子颜色 | 在现有颜色上再混入 15% 白色；手动颜色不覆盖 |
| 正等值面 | VMD lime，`#80E666` |
| 负等值面 | VMD cyan3，`#00C2FF` |
| 等值面不透明度 | 90%，即明显降低透明程度 |
| 选中原子绿色虚圈 | 线宽 3.5 → 9 |

**View → Lighting** 可独立打开四个不同方向的灯，默认打开前两个。灯光随相机方向工作，设置按文件保存，支持项目往返。详见 [外观说明](APPEARANCE_v3.8.0_CN.md)。

## 拖动与画布文字

Alt + 鼠标中键拖动片段原先每次鼠标移动都重建原子、键、边界、等值面和界面数据。现在平移时缓存静止与移动图形，只更新移动组的位置；松手后完整同步结构和面板。实际坐标、键关系与撤销仍保留。片段旋转继续使用原有路径。

选择 **Edit → Canvas text → Add text…**，输入内容后点击画布放置；点击文字选中，Alt + 中键平移、Alt + 左键旋转、Alt + 右键滚转。右击已有文字可编辑或删除，Delete 删除，Ctrl+Z 撤销。支持颜色、大小、粗体及字体文件；中文可选择支持汉字的字体文件。

文字位于三维空间，随整个结构视角旋转，独立保存在每个文档的项目数据中；包含在 PNG/GIF 出图中，不写入 GJF/XYZ/CIF 的原子数据。详见 [文字说明](CANVAS_TEXT_v3.8_CN.md)。
