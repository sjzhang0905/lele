# LELE 3.17.0

## 关联输出和轨迹

在左侧文件列表右击计算输出，选 **Associate file…**，再选择同一次计算的坐标轨迹。也可以先打开轨迹，从它的右键菜单选择输出文件。两个文件可以位于不同目录，关联结果以计算输出的文件名显示。保存为 `.lele` 项目会一并保存已加载的坐标和结果，重新打开项目即可查看。

| 计算 | 可选择的坐标文件 | 可查看的数据 |
| --- | --- | --- |
| CP2K 几何或晶胞优化 | 原生位置 XYZ，或带晶格的 CP2K EXTXYZ | 各优化步的能量、最大和 RMS 梯度、位移及打印的收敛阈值 |
| CP2K AIMD | 通常为 `项目名-pos-1.xyz`，可包含抽帧或续算步号 | 势能，以及输出中记录的温度、动能、守恒量。输出含完整原子力表时，可画每原子力模的最大值和均方根 |
| xTB 几何优化 | `xtbopt.log` 或相应的多帧 XYZ | 循环能量、轨迹注释中的笛卡尔梯度范数，以及输出打印的优化器梯度范数。两种梯度在图中各自标明单位 |

在 **Analysis → Energy / maximum-RMS convergence curves…** 打开曲线。点击有坐标的数据点，画布会显示该步的结构。CSV 可导出绝对能量、对应的几何帧号和可用的力或热力学数据。

CP2K 会按打印步号、可用的时间和能量核对轨迹。同一步内的线搜索试算保存在输出记录中，优化曲线选择有收敛汇总的步。若每隔多步才写一次坐标，中间各步的输出数值仍可查看，对应的几何帧号留空。原生 EXTXYZ 可逐帧携带变化的晶胞。

xTB 会核对可用的循环能量、元素顺序和最终坐标。若手动选择的普通 XYZ 没有步号和能量，只有单次计算且记录数一致时才按顺序配对，Results / info 会标明这一点。无法唯一匹配时，程序会提示原因。已编辑的独立副本会保留，磁盘上的输出和轨迹均按只读方式打开。

## 底部面板

Atoms selection 已移除索引起点和按回车选取的说明。Input / output text 原文页已从结构视图和纯结果视图移除。在 Results / info 中按 **Ctrl+C** 可复制选中的文字，没有选区时复制整栏。
