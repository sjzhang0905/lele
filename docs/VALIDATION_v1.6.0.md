# LELE 1.6.0 扩胞验证

日期：2026-10-27

## 源码基线

本包从可读取的 v1.3.0 源码重建，增加真实周期扩胞；未包含未恢复的 v1.4.0/v1.5.0 改动。
MIT 许可、窗口先显示再自动预加载、逐原子显示、频率动画及原有 GIF 导出均保留。

## 自动化检查

- 完整回归：**202 项测试、72 个子测试通过**。
- 斜晶胞 2 × 3 × 1：逐原子核对新分数坐标、笛卡尔位置、晶格行向量和六倍体积。
- 包裹与未包裹坐标分别验证；非周期方向不包裹且不能重复。
- 新原子的颜色、透明度、标签和原子分组正确复制；嵌套元数据独立于源帧。
- 手动键的最近周期路径、平移后的原子以及跨新晶胞缝的断键映射通过。
- 净电荷随晶胞数倍增；原能量清空，未推测新体系自旋多重度。
- 非正整数、非周期/奇异晶胞及超大原子数输入被拒绝，源结构与撤销记录不变。
- POSCAR Direct 和 CIF 实际写出后重新读取，原子数、晶格度量和体积正确。
- Qt 操作验证坐标表、原子总数、显示设置、暂停轨迹播放及其他帧不受影响。
- Ctrl+Z 恢复原原子数、坐标、晶胞、选择、能量和分离前的体数据。
- 扩胞对话框实时预览原子数，非周期方向倍数固定为 1；振动预览中入口禁用。
- 既有启动先绘制、几何编辑、选择、逐原子透明度、Gaussian 频率和 GIF 回归均通过。

## 原生界面与导出

使用真实 Qt 对话框及原生 VTK EGL 渲染验证：从菜单触发扩胞对话框，
将自带 `examples/Si_POSCAR` 从 8 原子扩为 2 × 2 × 1 的 **32 原子**结构。
新晶格为 `(10.862, 10.862, 5.431)` Å 的正交晶胞。
通过实际结构导出对话框写出 POSCAR 后重新读取，确认 32 个真实原子及相同晶胞。
PNG 保存按钮生成 **2044 × 1194** 图像；Undo 后回到 8 原子，输入文件字节未改动。

新界面截图来自自带硅晶胞示例，没有加入用户计算文件。
应用版本、欢迎页和 Windows 启动提示更新为 1.6.0。
构建 1.6.0 wheel 并核对版本、MIT 许可及 Python 模块与源码一致。

## 环境与范围

验证环境：Linux、Python 3.12、PySide6 6.12、ASE 3.29、VTK 9.7.1（EGL）和 Pillow 12.3。
此环境未构建 Windows EXE；Windows 请用本次源码运行 `build_windows.bat`。

扩胞仅作用于当前几何帧，是对真实原子和晶格的编辑。旧的计算能量和网格不会冒充新超胞结果。
当前功能为 a/b/c 正整数倍扩胞，不包含一般 3×3 整数变换矩阵。
