# LELE 3.16.0 更新

2026-11-18

## 片段旋转

选中片段中的一个原子，按住 Alt 并向左右拖动右键，即可绕视线方向转动整个相连片段。向水平方向移动一个逻辑像素即开始响应。松开鼠标后一次更新坐标表，按一次 Ctrl+Z 可撤销整次旋转。

常规球棍、空间填充、棍状和线框视图直接更新已有的原子、键、标签和选中轮廓。晶胞副本跟随各自的源原子，跨边界的半键和氢键虚线按端点移动。等值面和晶胞边框可以在整次拖动中复用。配位多面体、活动裁切或拟合面等依赖几何的视图会合并连续鼠标事件，并按最新坐标重绘。

## XSF 结构与等值面

直接打开以 `DIM-GROUP` 和 `3 1` 开头的 XSF 即可读取三维周期结构。元素符号、原子序数和笛卡尔坐标均可读取。早先使用的两个 Sn 表面模型各含 124 个原子，两个文件均只记录了结构。

带三维实空间标量网格的 XSF 可以直接绘制等值面。包内示例 [signed_field.xsf](../examples/signed_field.xsf) 含一组用于演示正负等值面的人工数据。

1. 将 XSF 拖进 LELE。在 **Field → Dataset** 选择网格通道。
2. 在 **Isosurface signs** 选择正值、负值或两者，在 **Isovalue** 调整阈值。初次打开 XSF 时，若默认双符号阈值完全落在数据范围外，LELE 会按该场的范围选取初始阈值。
3. 需要同时显示不同通道时，打开 **Surface layers / ESP mapping…**，为每一层选择数据及等值。已有匹配结构时，也可以用 **Import another field file…** 载入带网格的 XSF。

网格原点和三条跨度矢量采用 Å。沿每个方向的间距为跨度除以采样点数减一，数值按第一网格索引最快的顺序读取。对于完整晶胞上三个方向均含重复末端面的周期数据，LELE 使用唯一采样点做周期拼接。其余网格保留所有样本，包括边界两侧数值不同的情况。标量保留来源文件的单位。[XCrySDen 格式说明](https://web.mit.edu/xcrysden_v1.5.60/www/XCRYSDEN/doc/XSF.html)

## Style 滑杆与标题栏

每条滑杆的左右各半段分别映射默认值以下和以上的范围。切换显示模式、载入旧项目或切换文件时，滑杆按对应的实际数值定位。

| 控件 | 最小值 | 中点 | 最大值 |
|---|---:|---:|---:|
| Atom size，默认球棍模式 | 0.20 | 0.45 | 1.80 |
| Atom size，Space filling 模式 | 0.20 | 1.00 | 1.80 |
| Bond thickness | 0.03 | 0.05 | 0.35 |
| Bond cutoff，Chemcraft 模型 | 0.10 | 0.88 | 5.00 |
| Bond cutoff，Covalent radii 模型 | 0.10 | 1.18 | 5.00 |

主窗口标题栏使用与面板协调的中性灰。支持原生标题栏着色的 Windows 环境使用系统标题栏和窗口按钮，其他桌面环境使用 Qt 绘制标题栏，支持拖动、调整大小、最小化、最大化和关闭。

源码可通过 `start_windows.bat` 或 `python launch_app.py` 启动。同版本 wheel 位于 `dist/`。

性能测量、原始 XSF 样例核对与回归结果见[验证记录](VALIDATION_v3.16.0_CN.md)。
