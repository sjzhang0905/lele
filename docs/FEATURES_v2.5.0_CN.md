# LELE v2.5.0：长轨迹与大文件加载

本版取消程序固定帧数上限。完整的可识别轨迹不会因为超过 750 帧而被拒绝、抽帧或退回
仅最后一个结构。CP2K、VASP、Gaussian/ORCA、xTB、SIESTA 和通用多帧读取入口均使用
无上限的默认设置；xTB 和 NEB 的累计轨迹记录限制也已移除。

## 打开与浏览

照常使用 File → Open、拖入文件或命令行传入文件。较大的科学文件在后台解析，显示
Loading 与 Cancel；可在读取期间操作其他已打开文件。取消后保留现有文档，不添加
不完整的新文档。批量打开时按选择顺序处理。小文件和项目文件仍沿用原来的打开方式。

较长序列在 Files 树中显示为 `Frames 1–256`、`Frames 257–512` 等分组，展开时才创建
这一组的目录项。多阶段文件使用相应的 Steps 分组；没有坐标的能量使用 Records 分组。
**分组只影响目录显示，全部结构和能量数据都保留。** 可直接输入帧号跳至末帧，或继续
使用上一帧、下一帧与播放。步数、能量与坐标的缺失关系保持不变，不按条数配对其他文件。

切换阶段、NEB 路径/单个 image 历史及 GOAT 构象仍使用对应序列；项目保存与恢复仍保留
结构编辑、显示设置和选中的轨迹位置。Gaussian/ORCA 同一步重复打印的等价坐标继续按
既有规则处理，不把重复的坐标表误当作新动力学时间步。

## 加载优化

- CP2K XYZ、普通 XYZ 和 XDATCAR 按块读取并转换坐标，不再先建立完整的坐标文本行集合。
- 带 `Lattice`、`Properties`、周期方向和额外原子列的扩展 XYZ 继续交给 ASE，以保留元数据。
- 标准输出在一次导入中共用已解码文本，供结构、轨道、光谱、振动等读取；导入结束即释放缓存。
  再次打开同一路径会重新读取当前内容。
- VASP 参数与元素信息合并扫描，CP2K 略过不包含所支持记录的 SCF 诊断行；常规坐标/力表
  批量转换数值，保留非标准紧邻数字排版的兼容读取。
- 目录树共用帧序列索引，按需生成长序列节点；换帧不再重复复制和散列整段序列。

本版保留全部已解析结构于内存，**实际容量仍取决于可用内存及每帧原子数**。目录按需展开
不等于结构数据已实现磁盘分页，也没有承诺任意大小文件都可装入有限内存。
程序调用者仍可自行传入 `max_frames`；图形界面不传此限制，默认不设帧数上限。
取消在读取/解析检查点生效；其他第三方读取器的单次操作完成后才会响应取消。

VASP 仍只显示 E0；CP2K 仍使用原文件的 FORCE_EVAL/XYZ 注释能量，不自动改成外推 E0。
单文件读取、缺少能量或缺少结构的显示规则，以及编辑时保留手动键等既有行为保留。

性能数字、实际文件比对、十万帧验收和复现命令详见
