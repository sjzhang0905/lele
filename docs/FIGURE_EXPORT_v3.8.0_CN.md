# 图像导出（v3.8.0）

所有二维曲线窗口的工具栏“保存”现在统一默认导出 SVG，包含谱图、NMR、收敛曲线、几何参数、配位多面体指标、ORCA 分析、场切面和 VASP NEB 能量路径，以及 STM / XRD 的新绘图窗口。

- SVG 保留曲线/轮廓等矢量对象和可编辑文字；PDF 也可选。二维像素场本身仍按图像表达，不会伪装成结构矢量。
- PNG、JPEG、TIFF 导出先选择文件，再选择画布倍数或自定义宽度；高度保持画布比例。选择“Smooth edges”将以每边 2 倍像素渲染后用 Lanczos 缩小到指定像素。该选项不平滑或修改科学数据。
- 原子图例和 NEB 毛毛虫的三维渲染图使用 PNG，并弹出相同的分辨率、平滑选项。三维主画布的 PNG 导出保留原有高分辨率机制。
- 动画 GIF 保留已有的宽度、帧率、2 倍超采样和平滑、色彩抖动设置。
- 导出不会改变当前图的大小或原始数据；保存过程使用临时文件，写入成功后才替换目标文件。
