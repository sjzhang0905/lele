# LELE v2.11.0：周期结构的原点与局域坐标轴

日期：2026-11-02。

## 使用方法

在画布或坐标表中依次选择 **原点原子 → X 方向提示原子 → Z 方向原子**，点击 Edit 面板中的 **Set origin + X/Z axes…**。也可从菜单 **Edit → Reorient complete structure / crystal…** 打开窗口，直接填写原子编号。编号采用坐标表的全局编号，从 1 开始。

检查预览矩阵，然后点击 **Apply rotation**：

- 原点原子移至 `(0, 0, 0)`。
- Z 轴沿原点指向所选 Z 原子的方向。
- X 轴采用 X 提示方向在垂直于 Z 的平面内的投影，Y 按右手规则生成。该约定与提供的 v13 旋转脚本一致。
- 周期结构的原子坐标与全部晶胞矢量使用同一个旋转矩阵；长度、键角、晶胞体积和周期性邻接关系保持不变。

如果 X 提示键和 Z 键本来不垂直，刚性旋转无法把两根键同时精确变成正交的 X、Z。窗口显示原始夹角，并以 Z 为准正交化 X；不会拉伸或剪切结构。两方向共线或周期等价原子重合时给出提示。

周期结构默认勾选 **Use nearest periodic images around the origin**。轴方向和各原子代表坐标均使用真实晶格度量下的最近周期像，适用于斜晶胞，也尊重仅部分方向周期的设置。中心周围可出现正、负笛卡尔坐标，这与提供脚本的 `target-mic` 模式一致；原子数及编号不变。

## 使用对称性脚本的推荐矩阵

窗口的 **Define orientation** 选择 **Paste rotation matrix (row vectors)**，粘贴分析脚本的 `rotation_matrix_old_cartesian_row_to_local_row` 或对应 CSV 行向量矩阵。支持空格、逗号、分号和方括号分隔的 9 个数值。原点原子和最近周期像选项仍可独立设置。

采用行向量约定：

```text
r_new = (r_old + image_shift @ cell_old) @ Q + t
cell_new = cell_old @ Q
t = -origin_old @ Q
Q = R.T
```

Q 必须为行列式 +1 的正交矩阵。拉伸、剪切、镜像及非有限数值会被拒绝。预览框可直接复制矩阵；应用后的矩阵、平移及周期像平移保存在当前帧，并可在 **Results / info** 查看。保存 `.lele` 项目会保留这些记录。

## 提供的 POSCAR1 → POSCAR2

两份样例均含 100 个原子且顺序一致。目标原点是 **第 20 个原子**。要复现 POSCAR2，在 POSCAR1 中打开重定向窗口，选择粘贴矩阵模式、原点编号 `20`，保留最近周期像选项，粘贴：

```text
 0.286149357930  0.921945681546 -0.261026253918
-0.944978566688  0.316605205643  0.082320424321
 0.158537230506  0.223108278731  0.961815285024
```

该 Q 由两份样例的晶胞对应关系求得，用于验证完整晶体的刚性等价性。它不表示通过任意三个原子都能重现对称性分析脚本推荐的同一组轴；推荐轴也可以是配位环境拟合得到的方向。

采用完整精度矩阵时，100 个原子的最大笛卡尔坐标差约 **7.53×10⁻⁸ Å**，晶胞分量误差约 **1.78×10⁻¹⁵ Å**，体积由 4695.6302560431 Å³ 保持到浮点误差范围内。原始 POSCAR2 的原点有约 10⁻⁸ Å 的打印/生成残差，LELE 将选定原点置于数值零附近。使用上面的 12 位矩阵也通过独立实际文件断言。

## 原有单键对齐

选择两个原子后，**Align 1st → 2nd** 的 X/Y/Z 在周期结构中改为整体旋转晶胞与坐标，方向采用最近周期像；第一个原子保持在原位置。需要原点为零时可先移动原点，或使用新的原点＋X/Z 窗口。

`a/b/c` 指向当前晶格方向，保留为明确标注的“晶胞固定、旋转内部原子”的几何编辑。它会改变原子相对晶格的方向；整体同时旋转键与晶格无法改变它们的夹角。周期结构的坐标系重设请使用 X/Y/Z 或新的完整重定向窗口。

依次执行 X、Z 两次单轴对齐时，后一次旋转可能改变前一次对齐方向；同时定义两轴应使用新窗口。

## 数据、连接关系与保存

体数据的网格原点和体素矢量同步旋转/平移，数值不变。冻结的普通键、人工键和氢键的周期像平移会随原子代表坐标更新；跨边界键不会变成穿过画布的错误长线，Boundary 可继续显示其周期连接。

完整晶体的刚性重定向保留能量和优化收敛标记；如果只在固定晶胞中改变内部几何，则沿用已有失效处理。有完整 QE 力矢量时同步旋转，并更新笛卡尔分量统计；没有力矢量时不保留无法重新确定的最大分量。

**Ctrl+Z** 撤销坐标、晶胞、连接关系及附带网格几何。重定向后的 POSCAR（Cartesian 或 Direct）导出保留当前原子顺序和旋转后的晶胞。导出 Direct 时，分数坐标显示方式不同，但晶体与 Cartesian 输出相同。

操作作用于当前结构帧，同文件的其他轨迹帧保留原数据。耗时的最近周期像重排在后台处理，沿用长操作进度提示。
