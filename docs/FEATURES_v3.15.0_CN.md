# LELE 3.15.0 更新说明

日期：2026-11-17。基于上传的 LELE 3.14.0 源码包修改。

## 静电势与 electron/hole 图层

普通分子 CUBE 的采样盒不再被当作周期晶胞，默认 Boundary 不再产生重复分子或采样盒线框。明确具有周期性信息的网格继续保留周期显示。一般 CP2K/QE CUBE 自身没有可靠的周期性声明：若它来自晶体，可先打开匹配的 POSCAR/CIF/周期输出结构，再用 Field → Import another field file 导入 CUBE；坐标与晶胞匹配时可继续使用 Boundary。VASP、CASTEP 和带 LELE 周期元数据的 CUBE 保留其周期性。

Surface layers and color mapping 中选择图层后，直接在同一个窗口设置 Color field、配色、Min、Max 和色标。Min/Max 同时有输入框和滑杆，合法数值立即预览；Cancel 恢复打开前的设置。切换图层源场时，若旧等值面值不在新场的有效范围内，会给出合适的初值，并显示范围说明。electron 和 hole 两个非负场因此不会因为第二行继承负值而静默消失。

新增默认 **VMD RWB**，低值红、中点白、高值蓝；也提供反向 **VMD BWR**。自动范围使用颜色场的网格范围，白色位于 Min/Max 中点。仍可手动设置对称范围使零值为白色。已有项目中显式指定的旧配色仍按原有定义显示。表面材质跟随当前外观设置。色标去掉 `Layer 1: esp.cub` 一类标题行，保留单位。

此处采用 VMD 式颜色映射，不改变输入数据、网格单位或密度等值面值，也不承诺不同软件在相机、光照、材质、等值面阈值不同时得到完全相同的像素图。

## Scan 与文件列表

点击 Scan step 父节点会进入该扫描点优化序列的最后一帧；仍可展开并选择任一 Optimization cycle。

已加载文件支持右键重命名显示名称、Remove from loaded files 和打开所在文件夹。重命名只改变 LELE 内的名称；Remove 只卸载文档，不删除磁盘文件。

## Boundary 测距

测量保留实际点击的晶胞副本。相邻晶胞中的近邻原子不再被折回同一晶胞后按远距离测量；同一源原子的不同晶胞副本也可分别选中。对副本的跨晶胞测量仅供读取，避免把副本距离误写到原始结构中。

## 图片导出

静态图片导出窗口增加 **Cropped image** 选项，记住上一次确认的选择。裁剪前临时隐藏场景坐标轴，再去掉空白边缘，保留标签和色标。完成或失败后恢复主画布。裁剪后文件的实际像素尺寸可能小于所选画布尺寸。

主画布、批量图片、图例及毛毛虫图使用相同导出逻辑；普通曲线图仅裁剪边缘，不去掉数据坐标轴。

## 毛毛虫图与弹窗

毛毛虫图的环境原子继承当前主画布的颜色、原子/键尺寸、单原子外观、光照、Boundary 和相机投影等设置；被选择的移动原子继续使用路径示意图的显示方式。打开时继承主画布视角，Apply/导出刷新主画布外观，Use current main view 可再次同步完整相机。

弹窗通过所属 LELE 窗口保持前后关系，取消系统级始终置顶；切换到其他应用时，弹窗不再挡住其他应用。

## 使用与验证

源码启动方式与前版一致。包中包含同版本 Python wheel。Windows EXE 需要在 Windows 环境重新运行 `build_windows.bat` 构建。

验收范围与结果见 `docs/VALIDATION_v3.15.0_CN.md`。

配色实现参考：[VMD 官方 Scene.C](https://www.ks.uiuc.edu/Research/vmd/doxygen/Scene_8C-source.html)。
