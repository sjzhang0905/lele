# LELE v2.10.0：QE 输入、优化和声子

本版使用提供的四份 QE 7.3.1 文件补齐并验证读取功能。

| 文件 | 读取结果 |
| --- | --- |
| `01_vc-relax.in` | 4 原子 Cu₃N 输入结构、晶胞、坐标和 namelist 参数 |
| `job.out` | 5 个 PWSCF 求值记录及结构；变胞晶格、能量、笛卡尔最大/RMS力、最终收敛标记 |
| `job.out03` | PHONON 参考结构和 4 组 q 点、48 个频率；此文件未打印模式位移，保留频率而不生成动画数据 |
| `matdyn.modes` | 5 组 q 点、60 个归一化位移模式，保留重复出现的 Γ 点及原始负频率 |

通过 **File → Open** 打开这些文件即可，输出文件不必使用固定扩展名。

## 查看优化

打开 `job.out`，在左侧逐帧浏览、播放，或使用 Analysis 中的能量/收敛曲线功能。
最后一次最终结构 SCF 的能量与前面的几何优化求值分别保留，不以相同坐标为由
覆盖或合并。最后一帧显示 converged。

内部能量为 eV，单位换算沿用 ASE 的 QE 读取约定；原始 `! total energy` 的 Ry
数值另行保留并显示。最终原始总能量为 **−659.95599528 Ry**，晶胞边长
**3.826675649 Å**，体积 **56.03572023 Å³**。

输入读取支持 ASE espresso-in 的结构语法；本次实际验收为 `ibrav=0`，并覆盖
Angstrom、Bohr 和 crystal 坐标。未将全部 QE 模块、所有非零 ibrav 输入列为已验收。
不会自动打开输入中引用的 UPF、outdir 或 `.save` 目录。

## 查看和播放 matdyn 模式

1. 打开 `job.out03`，再打开 `matdyn.modes`。模式文件先作为独立结果打开，
   Results 中可查看各组 q 点的频率。
2. 选中模式文件，点击 **Analysis → Assign QE phonon reference…**。
3. 选择正确的参考结构及帧。对于这组文件，可以选择 `job.out03` 的参考结构。
   对照模式文件的行顺序确认原子顺序相同；模式文件本身没有元素名或坐标，
   原子数检查不能代替原子顺序核对。
4. 确认 **QE alat (q scale)**。本例从 PHONON 记录读出约 **3.82667619 Å**。
   应填写生成此模式文件时使用的 alat；它不一定等于变胞优化开始时的 alat，
   也不能一概用某条晶格向量长度替代。
5. 点击 OK，生成一个已关联参考结构的独立文件条目；原始模式结果继续保留。
   展开对应 q 点分组，选择模式，即可播放、画箭头、分析选中原子的
   位移参与度及导出 GIF/频率 CSV。

QE 这里的 q 是笛卡尔 **2π/alat** 单位，程序根据参考晶胞和 alat 转为平移相位。
启用 Boundary 重复晶胞后，相邻晶胞按 Bloch 相位运动。位移表的实部和虚部分别
保留，幅度由可视化控制调整；不会再次除以原子质量平方根。箭头显示一个实数
偏振相位的投影。负频率可作示意振动，不代表稳定的真实时间演化。

`.modes` 与质量加权 `.eig` 不是同一表示，本版不将 `.eig` 当作归一化位移读取。
没有位移的 PHONON 频率不会从另一份文件按频率近似匹配；没有 IR/Raman 强度时
也不会生成这些强度。

## 数据与保存

关联后的 q 点、复数位移的两部分、参考结构以及源文件读取结果均可保存在 `.lele`
项目中；频率 CSV 包含 q 坐标及单位。非刚性几何编辑会清除当前帧已失效的能量、
力和收敛标记，撤销可恢复。原始计算结果记录保持为源数据。

测试与实际文件记录见[验证报告](VALIDATION_v2.10.0.md)。本包为源码，Windows
独立 EXE 需要重新构建。所提供的四份原始计算文件未放入源码包。
