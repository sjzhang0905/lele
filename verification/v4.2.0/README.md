# LELE 4.2.0 验证

## 极值标注

通过独立安装的 wheel 打开 Qt 导入框，以本次提供的 `extrema_points.dat` 验证导入。五个金球的中心逐坐标核对一致，数值按文件顺序显示为 **29.7、22.9、19.9、0.5、−46.7**。原文件无单位标注，本次用默认 Å 读取坐标，能量保留原单位和原精度，仅将显示文字舍入到一位小数。另以独立样例核对了 Bohr 坐标换算。

在 Files 右击非当前文件并导入后，标注归属所点击的文件。验证了逐项调整字号、颜色、粗体和 XYZ 偏移，拖动标签、删除单点、撤销整组导入，以及另存项目后移走数据文件再重开。旋转和平移网格时，用变换后的坐标复核了金球的位置。字符大小和偏移以 Å 表示。

在独立的 1320 × 760 高清 PNG 上，逐点检查了五个预期投影位置的金色像素，以及各标签位置的文字像素。用一个碳原子的测试结构验证 POSCAR 与 GJF 写出并重读，两个文件的原子列表都只有该碳原子。

## 色标与自定义样式

分别检查了普通 CUBE 占位单位、Hartree/e 和 V 三种情形。ESP 映射的默认刻度端点均为 −0.03 和 +0.03。已知单位按原样显示，未知单位的色标只显示刻度。手动范围和自动范围均可重新选择。单独的空穴–电子功能仍绘制两层独立密度。

检查了当前和后台文档共用一个自定义样式时的删除行为，以及取消、写入失败、另一窗口保存其他样式和重启后重新读取设置。删除使用中的预设后，文档以 Custom (manual) 保留其外观。

## 回归结果

Linux、Python 3.12、Qt 离屏界面与 VTK OpenGL 环境下，2,433 项测试及 78 项子测试通过。14 项因缺少未随包分发的样例或可选依赖而跳过。Windows 桌面尚未实机验证。[完整回归记录](regression.xml)
