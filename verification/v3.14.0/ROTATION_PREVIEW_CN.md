# 旋转角滑块与实时预览验证

旋转对话框在角度输入框下增加 −180° 至 +180° 滑块，拖动步长为 0.1°；数值框保留四位小数及轴旋转 ±3600° 范围。拖动和直接修改数值均更新画布，二面角对话框也使用相同的实时预览方式。选中原子的说明仅显示从 1 开始的普通编号。

预览从不可修改的初始坐标计算，每次都生成独立显示副本，并冻结原有成键关系。实际文档、坐标、能量、修改标记和撤销栈均在预览期间保持不变。点击 Rotate／Set dihedral 才提交一次，产生一个撤销记录；取消或零角度／整圈旋转不会新增撤销记录。周期边及手工氢键的平移标记随最终几何正确更新，零角度还原原始晶胞代表坐标。

文档、帧、选择、原子坐标、晶胞、成键覆盖、氢键、成键阈值、元素对规则、成键模型或对齐状态发生外部变化时，预览失效。预览清理只重绘仍由自己占用的画布，从不把旧坐标写回文档，因此不会覆盖其他编辑或误改切换后的文件。显示样式和标签变化可继续保留有效预览。

自动回归覆盖实际鼠标拖动释放前的画布更新、细小／超出滑块范围的数值输入、反复修改无累积误差、轴上原子固定、普通与周期成键保持、取消、一次提交与一次撤销、源数据变化、无冻结快照时修改元素对规则、非模态源守卫、重复旋转对话框及切换文件。完整结果见 `rotation_preview_regression.log`。

另外使用真实 VTK EGL 离屏渲染生成了 `rotation_preview_before_after_cancel.png`。自动比较确认 +90° 预览改变了实际 framebuffer，而取消后的图像与原图逐像素相同。`rotation_slider_dialog.png` 是实际 Qt 对话框截图。该验证不是 Windows 原生窗口测试；Qt 交互回归使用无桌面的画布桩，独立 EGL 比较负责验证真实渲染输出。
