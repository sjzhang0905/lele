# LELE 4.5.0 验证

## 文本项目与兼容性

用 v4.4.0 原版程序生成了带晶胞、坐标、标量场、中文说明和共享结构引用的二进制项目。通过新版的 **File → Open project…** 打开旧项目，再通过 **Save project as…** 保存为 UTF-8 JSON。用标准 JSON 解析器读取并改动一个 Cartesian 坐标，重排缩进后重新打开，主窗口显示了编辑后的数值。测试也覆盖 Windows 换行、UTF-8 BOM、项目截断、数值缺失、保存中途取消及已有文件的完整性。

对一个 100 × 100 × 100 网格核对了全部单精度浮点数的位模式。原始数据与文本回读的数据逐点一致。另行检查了非连续数组、整数和布尔标记、复数系数、非有限值、空数组、共享引用和旧版显示设置的迁移。

## 等高线

用解析场 `f(x,y,z) = x` 测试二维切面、HKL 平面和选中原子拟合平面。范围 0 至 10 时设 4 个等高值，结果为 2、4、6、8。逐一检查了画布数值标签的位置与该处场值。改变等级数、单独关闭标签、固定色标、多个 HKL 面设置、常值场以及色标与数据无交集均有覆盖。

从独立安装的发行 wheel 启动主窗口，用 Qt 离屏窗口和 Mesa EGL 绘制实际图像。拟合面开关 5 个数值标签时有 3,322 个帧缓冲像素改变。Field 的二维切面开关 4 个等高值的标注时有 1,785 个图像像素改变。

## 菜单和快捷键

检查了主菜单中的重复项及保留的独立入口。通过标签页实际打开了扫描曲线，完成片段镜像、平面拟合和不同基底的 45° 视图旋转。在 Files 中打开了带坐标和仅有结果的 NEB 路径。焦点位于 Files 时，Ctrl+Shift+B 仍能启用框选，Esc 可退出。

## 完整回归

在 Linux 和 Python 3.12 上运行整套回归，2,519 项通过，另有 78 个子测试通过。14 项需要额外的外部科学样例，1 项需要 Windows 资源管理器桌面，这 15 项跳过。[完整测试记录](regression.xml)
