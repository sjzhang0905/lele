# LELE 4.3.1 验证

## 面板与菜单

在 Qt 的 Windows 和 Fusion 两种样式下，使用 1366 × 768 窗口并收窄底部面板。检查了 Axes 的旋转、位置、类型和长度各行，Labels 的字号、粗体和颜色，Boundary 的重复次数和操作按钮，以及 Style、Fragment 和 Atoms selection 对应的单行控件。各行的控件均完整可见。在 800 像素宽的窗口中，还验证了下方三栏互不遮挡，并可横向滚动到行末按钮。

Files 页的 Energy / RMS curves 使用三步纯能量文件实测。几何、扫描曲线的原入口以及 Analysis 中的振动筛选、轨道、NEB、GOAT 和 SOC 入口纳入回归。Edit 以 Mirror selected fragment 开头，Net charge 后紧接 Move selected atom to (0, 0, 0)。

## 项目兼容与绘制

验证坐标轴三个位置按钮、晶轴与笛卡尔轴的切换、XYZ 长度滑杆两端、数值精调和项目重开。旧项目中隐藏的多晶胞 Boundary 重开为一个晶胞。旧项目中已保存的元素与 ORCA 编号组合标签和字体设置可读取，也可改用当前选项。单晶胞含表面镜像的原子数超过显示上限时可绘制原始结构。切换到镜像数量在上限以内的下一帧后，可以重新显示周期镜像。

从单独安装的发行 wheel 经欢迎页启动，读取真实 EGL 帧缓冲，验证水分子的 45° 旋转及反转。打开硅晶体后，沿第一晶轴复制使可见位置从 18 个增至 31 个，重置后恢复 18 个。另通过控件切换坐标轴、调整长度、按表达式选择原子及打开 Files 能量曲线。用两份 CUBE 从 Analysis 生成 ESP 表面并导出 1000 × 650 PNG，检查了实际图像和半宽色标。
