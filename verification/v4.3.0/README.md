# LELE 4.3.0 验证

## ESP 色标

在同一场景中使用同一份数值网格绘制两条色标，其中一份显式赋予 ESP 角色。检查了两条色标的位置、高度、单位、五个刻度设置和映射范围。在 800 × 500 的实际导出 PNG 中逐像素比较了两条彩带。三维切面也按所显示的物理场选择色标长度。独立二维切片图检查了竖向色标的长度和厚度。

## 固定步长旋转

在已平移和倾斜的相机上，分别用透视和正交投影验证九种旋转轴。对照独立旋转矩阵检验了正负方向、连续八步回到原视角，以及原子坐标、晶胞、缩放与投影。另测了倾斜晶胞、经过轨迹对齐的二维晶胞，以及分子与晶体之间切换时可选的晶轴。

## Windows 文件侧栏

在真实 Qt 打开、多选、保存和目录选择窗口中，用模拟的资源管理器结果覆盖重定向桌面、中文显示名、自定义固定目录、去重、取消固定和实际点击跳转。校验了后台更新时当前目录和输入文件名、弹窗关闭后 Qt 自有书签，以及异步查询缓存和异常输出处理。当前主机为 Linux。Windows Shell 实机检查作为独立测试保存在 tests/test_windows_places_v430.py 中。

## 发行包和回归

在隔离目录安装随包 wheel，从欢迎页打开 water.xyz，读取真实 EGL 帧缓冲并通过菜单旋转、反转。随后通过 Analysis 的 ESP 弹窗以两份 CUBE 生成着色表面，检查色标位置和宽度并导出 1000 × 650 的高分辨率 PNG。

Linux 上执行的结果见下方，15 项跳过包括 14 项需要外部样例的测试和 1 项需要 Windows 桌面的测试。[完整回归记录](regression.xml)
