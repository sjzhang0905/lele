# LELE 4.2.2 验证

## 显示默认值和极值入口

在桌面界面和 VTK 场景分别检查了灯光开关，以及高光大小、亮度滑杆传给原子、键和表面的实际材质值。默认启用 Front、Upper right，滑杆的键盘单步为 1，两个初始值均从 50 调至 47。使用两个 CUBE 生成密度表面和 ESP 着色，并检查表面实际不透明度为 0.50。普通正负等值面和电子、空穴两层也分别核对了默认值。

在 Files 中分别右击普通结构、裸网格、空穴–电子结果、专用 ESP 结果和手动映射了 ESP 的文件。检查了文件切换后右击后台文件以及解除映射后的菜单，还验证了普通结构文件名含 ESP 时的行为。用 v4.2.2 安装包实际打开 v4.2.1 项目，复核了旧项目保存的三灯组合、高光两个 50、等值面不透明度 0.90 以及全部五个极值标注。

## 图片背景

以下检查读取最终输出文件。位图背景按 RGB 各通道均为 255 判断，支持 alpha 的格式同时检查背景完全不透明。

| 输出 | 验证内容 |
| --- | --- |
| 单张、批量 PNG | 从深色画布导出单张，以及两个不同背景文档的批量图。分别核对边缘背景、选中帧和导出后恢复的视图。 |
| ESP、元素图例和 NEB 毛毛虫图 | 用两份 CUBE 生成 ESP 图，并在原始分辨率和高清导出下检查。深色背景下的图例文字在白底导出时使用深色，导出完成和中断后均恢复场景设置。 |
| GIF | 对开启和关闭抖动的三帧轨迹逐帧解码，四角均为纯白。 |
| 分析图 PNG、JPEG、TIFF | 使用有色页面、着色绘图区以及要求透明保存的绘图环境导出，检查页面四角和绘图区空白处。 |
| 分析图 SVG、PDF | 将矢量文件重新渲染到带透明通道的画布，确认页面四角和绘图区均为不透明纯白。 |

Linux、Python 3.12、Qt 离屏界面和 VTK OpenGL 环境下，2,448 项测试和 78 项子测试通过。14 项因缺少外部样例或可选依赖而跳过。Windows 桌面尚未实机验证。[完整回归记录](regression.xml)
