# LELE 3.18.0 验证记录

Linux、Python 3.12、PySide6 和 VTK 环境下，完整回归通过 2359 项及 78 项子测试，14 项因缺少外部样例跳过。逐项结果见 [regression.xml](regression.xml)。

| 功能 | 核对内容 |
| --- | --- |
| 右键旋转 | 正交、透视、偏离画布中央的非对称结构和 Boundary 重复显示。整体旋转的投影与绕全部原子坐标均值计算的投影相符。Alt＋右键从不同位置起拖得到相同结果，片段中心固定，其他原子坐标逐项一致。 |
| 片段镜像 | 默认 YZ 镜像反转四点的有向体积。验证另两个平面、坐标原点、跨晶胞点选的显示副本、未选原子、晶胞和撤销。 |
| 高光大小 | 实际离屏渲染一个 384 × 384 像素的单球。在相同材质、灯强、镜头和像素亮度阈值下，滑杆取 0、50、100 时，高光像素数依次为 148、316、9468。检查旧预设、项目重开和独立图例，拖动时复用原有几何。 |
| 本地坐标文件 | 双向选择未加载的文件，另测 Direct、Cartesian、混合 T/F、无 Selective dynamics、元素块与重复势、增删原子、速度表、MD 历史以及备份。重新打开写出的 POSCAR 和 CONTCAR，核对坐标、晶胞与每一行约束。 |

原子数增加时，有速度表的目标文件为新增原子补零初速度。若修改的 CONTCAR 带有原几何的 MD 预测校正历史，预览会说明这部分只保留在原文件备份中。
