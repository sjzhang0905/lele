# 3.17.0 验证记录

完整测试通过 2339 项和 78 项子测试。14 项因缺少对应外部样例跳过。逐项结果见 [regression.xml](regression.xml)，跳过原因与安装包校验值见 [checks.json](checks.json)。

| 输入 | 核对内容 |
| --- | --- |
| 128 原子 CP2K 几何优化输出和位置轨迹 | 逐帧核对 134 个轨迹结构及其能量，另保留输出中的初始几何，共 135 帧。133 步包含最大梯度和 RMS 梯度 |
| 309 原子 CP2K 优化输出 | 151 次 FORCE_EVAL 能量求值对应 145 个优化汇总，各汇总均含最大梯度和 RMS 梯度 |
| 329 原子 xTB 优化输出和 xtbopt.log | 核对 37 个循环、37 帧坐标、最终单点能量和两种梯度范数 |
| 216 原子 RuO₂ AIMD 输出和同次计算的第 2300 步重启结构 | 从重启文件导出仅含步号、时间、晶胞与坐标的单帧 EXTXYZ。关联后保留 3001 条输出记录，核对了第 2300 步的坐标、时间、势能和温度 |
| dpdata 0.2.17 原生 CP2K 输出与 XYZ | 533 原子 REFTRAJ 的 30 帧全部匹配。5 原子 NVT 的 7 条输出记录对应 1 个保存的轨迹帧 |

以上数据的数值核对见 [paired_files.json](paired_files.json)。公共测试样例来自 dpdata 源码发行包的 tests/cp2k/aimd 和 tests/cp2k/aimd_stress。[dpdata 0.2.17](https://pypi.org/project/dpdata/0.2.17/)

Qt 界面测试覆盖双向关联、已加载文件合并、错误配对、曲线点击跳帧、CSV、项目脱离原文件重开，以及两个结果面板中的剪贴板操作。另在 Linux 隔离安装了本版 wheel，用 Qt 与 EGL 离屏渲染运行主窗口、打开关联数据并检查实际三维像素和曲线。
